## Authentication

### `authSendOtp(email: string): Promise<AuthSendOtpResponse>`

Sends an OTP code to the user's email address via SendGrid.

**Parameters:**
- `email` (string, required): User's email address

**Returns:**
```typescript
{
  success: boolean
  message: string
}
```

**Usage:**
```typescript
const response = await authSendOtp('user@example.com');
if (response.success) {
  console.log('OTP sent:', response.message);
}
```

**Errors:**
- `auth_required` - User must be authenticated
- `invalid_email` - Email format is invalid
- `email_send_failed` - Email service error

## Chat

### `chatSend(request: ChatSendRequest): Promise<ChatSendResponse>`

Sends a chat message and gets an AI response.

**Parameters:**
```typescript
{
  threadId?: string              // existing thread ID (generated if omitted)
  message: string                // required: user message
  mode: string                   // required: 'assistant' | 'consultant' | 'therapist'
  language?: string              // BCP-47 language code, default: 'en'
  attachments?: any[]            // optional: context from notes, checklists, etc.
  generationConfig?: {           // optional: control generation behavior
    temperature?: number         // 0.0 to 1.0
    maxTokens?: number          // max output tokens
  }
}
```

**Returns:**
```typescript
{
  success: boolean
  threadId: string               // thread ID for this conversation
  response: {
    role: 'assistant'            // fixed
    content: string              // AI response text
    toolCalls?: any[]            // AI-generated tool invocations
    generatedImages?: any[]      // images generated by AI
  }
  tokensUsed?: number            // tokens consumed
}
```

**Usage:**
```typescript
const response = await chatSend({
  threadId: 'thread-123',
  message: 'What are modern wedding themes?',
  mode: 'assistant',
  language: 'en',
});

console.log('Response:', response.response.content);
console.log('Tokens:', response.tokensUsed);
```

**Errors:**
- `auth_required` - User must be authenticated
- `message_required` - Message cannot be empty
- `mode_required` - Mode must be specified
- `chat_generation_failed` - AI service error

## Images

### `imagesGenerate(request: ImagesGenerateRequest): Promise<ImagesGenerateResponse>`

Generates images using DALL-E 3.

**Parameters:**
```typescript
{
  prompt: string                 // required: image description
  style?: string                 // optional: 'realistic' (default) | 'artistic' | 'minimalist'
  size?: string                  // optional: '1024x1024' (default) | '1024x1792' | '1792x1024'
  quantity?: number              // optional: 1-4, default: 1
  referenceImage?: string        // optional: base64 image for reference
}
```

**Returns:**
```typescript
{
  generationId: string           // unique ID for this generation
  status: 'completed' | 'failed'
  prompt: string                 // original prompt
  style?: string
  size?: string
  quantity: number
  generatedUrls: Array<{
    url: string                  // download URL (7-day validity)
    revisedPrompt?: string       // actual prompt used (may differ)
    createdAt: Date              // generation timestamp
  }>
}
```

**Usage:**
```typescript
const response = await imagesGenerate({
  prompt: 'Modern wedding decoration with flowers and lights',
  style: 'realistic',
  size: '1024x1024',
  quantity: 2,
});

response.generatedUrls.forEach(img => {
  console.log('Image URL:', img.url);
  console.log('Actual prompt:', img.revisedPrompt);
});
```

**Errors:**
- `auth_required` - User must be authenticated
- `prompt_required` - Prompt cannot be empty
- `image_generation_failed` - AI service error

## Payment

### `paymentInitiate(request: PaymentInitiateRequest): Promise<PaymentInitiateResponse>`

Initiates a payment transaction via PayU.

**Parameters:**
```typescript
{
  plan: string                   // 'pro_monthly' | 'pro_annual' | 'promax_monthly' | 'promax_annual' | 'topup_2m'
  billingCycle: string          // 'monthly' | 'annual' | 'once'
  currency: string              // 'USD' | 'INR' | 'GBP' | 'EUR' | 'AUD' | 'CAD' | 'JPY' | 'AED' | 'SGD'
  billingAddress: {
    name: string                // full name
    email?: string
    phone?: string
    country: string             // 2-letter country code
    state?: string              // required for IN
    city: string
    line1: string               // address line 1
    line2?: string              // address line 2
    postalCode: string
    gstin?: string              // India GST number (optional)
  }
  isUpgrade?: boolean            // true if upgrading existing subscription
}
```

**Returns:**
```typescript
{
  orderId: string               // unique order identifier
  status: string                // 'initiated' | 'failed'
  amount: number                // final amount in specified currency
  currency: string
  payuUrl?: string              // direct redirect URL (if available)
  failureReason?: string        // reason if status is 'failed'
}
```

**Usage:**
```typescript
const response = await paymentInitiate({
  plan: 'pro_monthly',
  billingCycle: 'monthly',
  currency: 'INR',
  billingAddress: {
    name: 'John Doe',
    country: 'IN',
    state: 'Maharashtra',
    city: 'Mumbai',
    line1: '123 Main Street',
    postalCode: '400001',
  },
});

if (response.payuUrl) {
  window.location.href = response.payuUrl;
}
```

**Errors:**
- `auth_required` - User must be authenticated
- `invalid_plan` - Plan code not recognized
- `subscription_validation_failed` - User cannot upgrade (wrong state)
- `exchange_rate_failed` - Currency conversion error

### `paymentVerify(request: PaymentVerifyRequest): Promise<PaymentVerifyResponse>`

Verifies payment completion.

**Parameters:**
```typescript
{
  orderId: string               // order ID from paymentInitiate
  payuTransactionId: string     // PayU transaction ID
}
```

**Returns:**
```typescript
{
  verified: boolean             // payment successful
  status: string                // 'success' | 'failed' | 'pending'
  message: string
}
```

**Usage:**
```typescript
const verified = await paymentVerify({
  orderId: 'order-123',
  payuTransactionId: 'payu-txn-456',
});

if (verified.verified) {
  console.log('Payment confirmed!');
}
```

**Errors:**
- `auth_required` - User must be authenticated
- `invalid_order_id` - Order not found

## Subscription

### `subscriptionCurrent(): Promise<SubscriptionCurrentResponse>`

Retrieves current subscription state.

**Parameters:** None

**Returns:**
```typescript
{
  state: string                 // 'free' | 'guest' | 'pro_monthly' | 'pro_annual' | 'promax_monthly' | 'promax_annual' | 'cancel_scheduled'
  plan?: string                 // 'pro' | 'promax'
  billingCycle?: string         // 'monthly' | 'annual'
  currentPeriodStart?: string   // ISO 8601 timestamp
  currentPeriodEnd?: string
  nextRenewalAt?: string
  cancelAtPeriodEnd?: boolean
  downgradeToOnPeriodEnd?: string  // plan to downgrade to
  forwardCreditUsd?: number     // credit from upgrade
  status: string                // 'active' | 'cancelled' | 'expired'
}
```

**Usage:**
```typescript
const subscription = await subscriptionCurrent();

console.log('Current plan:', subscription.plan);
console.log('Expires:', subscription.currentPeriodEnd);
console.log('Forward credit:', subscription.forwardCreditUsd);
```

**Errors:**
- `auth_required` - User must be authenticated

### `subscriptionUpgrade(request: SubscriptionUpgradeRequest): Promise<SubscriptionUpgradeResponse>`

Upgrades to a higher subscription tier.

**Parameters:**
```typescript
{
  newPlan: string               // 'pro_monthly' | 'pro_annual' | 'promax_monthly' | 'promax_annual'
  billingCycle?: string         // 'monthly' | 'annual'
  clientRequestId: string       // unique request ID (prevents duplicates)
}
```

**Returns:**
```typescript
{
  state: string                 // new subscription state
  creditApplied: number         // pro-rata credit USD
  invoiceId?: string            // synthetic invoice ID
  orderId?: string              // order ID if payment required
  message: string
}
```

**Usage:**
```typescript
const upgrade = await subscriptionUpgrade({
  newPlan: 'promax_monthly',
  clientRequestId: `upgrade-${Date.now()}`,
});

console.log(`Upgrade successful! $${upgrade.creditApplied} credit applied.`);

// If payment required
if (upgrade.orderId) {
  const payment = await paymentInitiate({
    plan: 'promax_monthly',
    billingCycle: 'monthly',
    currency: 'USD',
    billingAddress: {...},
  });
}
```

**Errors:**
- `auth_required` - User must be authenticated
- `invalid_transition` - Cannot upgrade from current state
- `missing_client_request_id` - clientRequestId required

### `subscriptionDowngrade(request: SubscriptionDowngradeRequest): Promise<SubscriptionDowngradeResponse>`

Schedules subscription downgrade at end of billing period.

**Parameters:**
```typescript
{
  clientRequestId: string       // unique request ID (prevents duplicates)
}
```

**Returns:**
```typescript
{
  state: string                 // new state (usually '*_cancel_scheduled')
  applied: boolean              // downgrade scheduled
}
```

**Usage:**
```typescript
const downgrade = await subscriptionDowngrade({
  clientRequestId: `downgrade-${Date.now()}`,
});

if (downgrade.applied) {
  console.log('Downgrade scheduled for next billing period');
}
```

**Errors:**
- `auth_required` - User must be authenticated
- `invalid_transition` - Cannot downgrade from current state

### Error Types

All functions throw JavaScript `Error` objects with additional properties:

```typescript
try {
  await chatSend(request);
} catch (error: any) {
  // error.message - human-readable error
  // error.code - error code string
  // error.details - additional context (varies by function)
  
  switch(error.code) {
    case 'auth_required':
      // Handle auth
      break;
    case 'quota_exceeded':
      // Show upgrade prompt
      break;
    default:
      // Generic error
  }
}
```

## Error Handling

### Common Error Codes

| Code | HTTP | Meaning | Solution |
|------|------|---------|----------|
| `auth_required` | 401 | User not authenticated | Redirect to login |
| `permission_denied` | 403 | User lacks permission | Check auth |
| `invalid_argument` | 400 | Bad request data | Validate inputs |
| `not_found` | 404 | Resource not found | Check IDs |
| `quota_exceeded` | 402 | Usage limit reached | Upgrade plan |
| `internal` | 500 | Server error | Retry with backoff |
| `unavailable` | 503 | Service unavailable | Retry later |

### Error Handling Pattern

```typescript
try {
  const result = await chatSend(request);
  // success
} catch (error: any) {
  if (error.code === 'auth_required') {
    // Redirect to auth
    window.location.href = '/login';
  } else if (error.code === 'quota_exceeded') {
    // Show upgrade
    showUpgradeDialog();
  } else if (error.code === 'internal' || error.code === 'unavailable') {
    // Retry with backoff
    setTimeout(() => retry(), 1000);
  } else {
    // Show error to user
    showError(error.message);
  }
}
```

## Best Practices

### 1. Always use try-catch
```typescript
try {
  const response = await chatSend(request);
} catch (error) {
  // Handle error
}
```

### 2. Use unique IDs for payments/subscriptions
```typescript
// Prevents duplicate operations on retry
const clientRequestId = `operation-${Date.now()}-${Math.random()}`;
```

### 3. Store responses in Firestore
```typescript
// After chat response
await addMessage(threadId, {
  role: 'assistant',
  content: response.response.content,
  timestamp: new Date(),
});
```

### 4. Handle quota errors gracefully
```typescript
if (error.code === 'quota_exceeded') {
  // Show upgrade prompt with details
  showUpgradeDialog(error.details);
}
```

### 5. Log errors for debugging
```typescript
catch (error: any) {
  console.error('[functionName] Error:', {
    code: error.code,
    message: error.message,
    details: error.details,
    timestamp: new Date().toISOString(),
  });
}
```

## Support & Troubleshooting

**Check logs:**
- Browser console: Frontend errors
- Firebase console: Function execution logs
- Cloud Firestore: Database writes

**Common issues:**
- `auth_required`: Ensure user is logged in before calling functions
- `permission_denied`: Check Firestore security rules
- `unavailable`: Cloud Function cold start (will succeed on retry)
- `quota_exceeded`: User has exhausted usage limits

For detailed logs, check Firebase Console → Cloud Functions → Logs
