## Description

Multiple components use the same `<div onClick={() => close()}><div onClick={e => e.stopPropagation()}>…</div></div>` overlay pattern with no `role="dialog"`, no `aria-modal`, no focus trap. Affects:
- `ImageActions.tsx:283` — share modal for image artifacts
- `GalleryView.tsx:236` — image preview overlay (no aria-modal, no Esc handler)
- `ImageCarousel.tsx:140` — carousel overlay

These are click-to-dismiss for mouse users but a keyboard user can't dismiss them (no Esc binding visible), and SR users get no context.

## Notes

Bundle with WE-20260528-281 — same root cause, same fix pattern (use Radix Dialog or build a `<Modal>` primitive with proper a11y).
