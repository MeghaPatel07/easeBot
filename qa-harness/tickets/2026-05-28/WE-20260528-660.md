## Description

The "Share conversation" modal is implemented as a raw `<div>` with `fixed inset-0 z-[10000]` and onClick-to-close. It has:

- No `role="dialog"` / `aria-modal="true"`
- No focus management — Tab walks straight out of the overlay onto the page behind
- No `DialogTitle` association — the visible `<h3>` is not linked via `aria-labelledby`
- Escape does not close it (only the backdrop click does)
- No focus return to the trigger after close

Different from -264 (ImageCarousel preview) — this one is the chat-thread share modal in Index.tsx, with a separate code path.

## Steps to reproduce

1. Open a chat thread
2. Click "Share" on the thread menu
3. Press Tab repeatedly — focus walks into the chat behind
4. Press Escape — modal stays open

## Expected

Migrate to Radix `<Dialog>` from `@radix-ui/react-dialog` (already imported elsewhere in repo). DialogTitle + DialogDescription, automatic focus trap, Escape handling, focus return.

## Actual

Bespoke overlay, no a11y plumbing.

Same code pattern appears in `shareModalJSX` in 4 places (Index.tsx lines 1181, 1212, 1393, 1510) — one component, multiple render sites. One fix.
