## Steps to reproduce
1. Tab A: Settings → Subscription. Currency override dropdown — switch from INR to USD.
2. Tab B: navigate to `/pricing` (open BEFORE the change). All prices still show ₹ values.

## Expected
Tab B reflects USD prices within ~1 s.

## Actual
`geolocationService.ts:74-79, 91-92` reads localStorage on demand; no listener. React state in pricing components captured the value on mount.

## Impact
P1 — pricing display inconsistency; user could be tricked into thinking pricing differs between tabs, or paying in the wrong currency.

## Fix direction
- Add `storage` listener in geolocationService or wrap the read in a hook that subscribes.
- Add a `useCurrency()` hook with a tiny store (Zustand) + cross-tab BroadcastChannel.

## Evidence
- `src/services/geolocationService.ts:32-117`
- Live probe confirmed `eb_currency_override` flag set in tab A is visible in tab B's localStorage but React state does not reload.
