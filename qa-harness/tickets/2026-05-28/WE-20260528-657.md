## Description

The Gallery loading state renders:

```jsx
<div className="flex flex-col items-center justify-center py-20 text-center space-y-3">
  <Loader2 className="h-6 w-6 text-primary animate-spin" />
  <p className="text-sm text-foreground/50">Loading gallery...</p>
</div>
```

There is no `role="status"`, no `aria-live`, no `aria-busy`. SR users navigating into the gallery hear silence until the images grid populates. With slow networks or large galleries, this is 1-5 seconds of unexplained silence.

Same pattern likely affects other lazy-load lists (RemindersView, ChecklistDetail item fetch, NotesView list).

## Steps to reproduce

1. SR on, throttle network to "Slow 3G"
2. Sidebar → Gallery
3. Observe — no audible signal of loading or completion

## Expected

Wrap loading state with `role="status" aria-live="polite"`; spinner Lucide icon has `aria-hidden="true"` so it doesn't get announced as "image". When images settle, announce "Loaded {n} images" once.

## Actual

Silent.

## Notes

Audit similar patterns in: RemindersView, SavedItemsView, NotesView (notes-list pane), BillingSettingsSkeleton (already has role=status — confirm), settings/tabs/AiBehaviorTab.
