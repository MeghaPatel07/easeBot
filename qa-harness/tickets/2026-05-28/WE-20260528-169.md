## Description

Cross-tab variant of WE-20260528-157. Since the liked-messages collection is fetched once at login per tab, any like performed in Tab A is invisible in Tab B for the entire session. Also, since Tab A doesn't update its own liked-collection without reload (157), and Tab B doesn't see Tab A's change without reload, the only way to "see all liked messages" honestly is to reload both tabs.

## Steps to reproduce

1. Tab A and Tab B both signed in as same user. Both have Liked-messages view open.
2. In Tab A, like a new AI message.
3. Watch Tab B's Liked-messages view.

## Expected

New like appears in Tab B within ~1 s.

## Actual

Tab B's list is unchanged. Tab A's own list is also unchanged (see 157).

## Evidence

- Screenshot(s): `qa-harness/evidence/WE-20260528-169/screenshots/`

## Notes

Same fix as 157 — install per-thread onSnapshot listeners with `where('liked','==',true)` instead of a one-shot getDocs.
