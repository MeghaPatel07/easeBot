## Steps to reproduce
1. Tab A and Tab B open at `/`. Both have aspect ratio set to 1:1.
2. Tab A, change to 16:9.
3. Tab B, generate an image.

## Expected
Tab B uses 16:9.

## Actual
- Tab B reads from React state initialized from `localStorage.getItem('easebot-image-aspect-ratio')` on mount. No storage event listener, uses 1:1.
- Inconsistent with Tab A user expectation.

## Suggested owner
fix-state-data
