## Description

Re-verification: the shadcn `Button` `cva` base classes still ship `focus-visible:ring-1 focus-visible:ring-foreground/10`. A 1px ring at 10% opacity does not meet the 3:1 non-text contrast required by 1.4.11 against the foreground/background. Tabbing through any page produces no perceivable focus indicator on Button-derived elements unless the underlying browser also paints its own ring (which `focus-visible:outline-none` explicitly suppresses).

WE-20260527-256 was filed yesterday with the same root cause; checking today's main branch the fix has not landed. Listing here for QA visibility, **not** to create duplicate work.

## Steps to reproduce

1. Tab through `/pricing`, focus the "Continue" Button or any tier CTA.
2. Observe focus ring (or lack thereof).

## Expected

≥ 2px outline/ring at 3:1 contrast against both light + dark themes.

## Actual

Effectively no visible focus.

## Notes

Suggest aligning with the global `:focus-visible` rule already added in `index.css` per WE-20260527-256 — possibly overridden by button's own `focus-visible:outline-none`.
