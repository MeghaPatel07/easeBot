## Steps to reproduce
1. Sign in same user in Tab A and Tab B.
2. In Tab A, hit Sign out (Profile menu).
3. In Tab B, click around — Settings, Chat send, Reminders.

## Expected
Tab B should auto-redirect to sign-in modal or show "You've been signed out elsewhere".

## Actual
- Firebase SDK does broadcast auth state changes between tabs of the same origin via IndexedDB.
- `onAuthStateChanged` fires in Tab B with `firebaseUser === null`, handler sets profile = null, user = null. UI should react.
- BUT the `isHandlingAuth.current` guard at AuthContext.tsx:89 can intercept this if a sign-in/up is in flight. Even when it is not, the redirect to /login is not enforced — Tab B will keep showing the previous page with `user === null`, leading to confusing 401s on next request.
