## Description

NoteEditor-D1BRRvzy.js (513KB raw, 158KB gzipped) is included in the initial network waterfall on /chat (confirmed via Lighthouse network-requests audit). Lighthouse unused-javascript reports 138KB (90%) of this bundle is wasted on /chat.

Root cause: src/pages/Index.tsx line 32 has 'import NotesView from "@/components/notes/NotesView";', and NotesView.tsx line 29 has 'import NoteEditor from "@/components/notes/NoteEditor";'. Because Index renders on every primary route, TipTap's massive bundle (table, image, task-item, text-align, character-count, etc.) ships with every page load even when the user never opens Notes.

App.tsx already uses React.lazy for top-level routes — same pattern should apply here.

## Steps to reproduce

1. npm run build
2. npx vite preview --port 4173
3. Open /chat/anything in DevTools Network tab — NoteEditor-*.js is requested

## Expected

NoteEditor chunk should be loaded only when sidebarView === 'notes' (or /:userId/notes/* routes).

## Actual

NoteEditor is loaded immediately for any user landing on / or /chat; 90% of its bytes are unused on those pages per Lighthouse.

## Notes

Fix: Change 'import NotesView from ...' in Index.tsx to 'const NotesView = lazy(() => import("@/components/notes/NotesView"))' and wrap in Suspense at the sidebarView==='notes' branch. Same for other heavy views (BudgetDashboard, TimelineView, ProgressDashboard, ShoppingListView).
