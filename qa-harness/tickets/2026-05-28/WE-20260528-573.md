## Steps to reproduce
1. Sign in via tab A with Remember-me ticked → email saved.
2. Sign out, close tab A.
3. In tab B (still open), trigger SignInModal — email is pre-filled.
4. User uncheck Remember-me, removes localStorage value.
5. Open new tab C → SignInModal pre-fills (it shouldn't).

## Expected
Other tabs' SignInModal should pick up the change.

## Actual
`SignInModal.tsx:63-65` reads on mount only. localStorage state is shared but not subscribed.

## Impact
P3 — minor privacy / UX. Could matter for shared family device.

## Fix direction
`storage` listener for `weddingease_remember_email` key.

## Evidence
- `src/components/auth/SignInModal.tsx:63-65, 188-189`
