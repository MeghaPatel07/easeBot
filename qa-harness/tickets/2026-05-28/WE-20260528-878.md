## Description

The shadcn Dialog overlay is `bg-[rgb(73_61_54/0.12)] backdrop-blur-sm`. At 12% opacity warm-brown, the overlay is **too subtle**:
- Underlying chat is fully readable through the overlay.
- Visual focus doesn't shift cleanly to the modal.
- On bright laptop screens (sun, outdoor), the 12% opacity is functionally invisible and users may not realize a modal is open vs an inline panel.
- backdrop-blur-sm helps a little but isn't enough for crowded chat backgrounds.

Industry standard is 40-60% black/dark overlay. Sprint 2 audited dark-mode tokens; the overlay token wasn't on that list.

## Steps to reproduce

1. Open /chat with several messages visible.
2. Open Settings.
3. Observe: chat is still clearly visible behind the modal.
4. Compare with iOS Mail / Gmail modals which clearly fade the background.

## Expected

Increase to `bg-[rgb(0_0_0/0.4)]` or theme-aware `bg-overlay-scrim/40` (token already exists per GalleryView use of `bg-overlay-scrim/90`).

## Actual

12% warm-brown — feels like a hint, not a focus shift.

## Evidence

- dialog.tsx:22 cited.
- Sprint 1 ticket -054 covered dark-mode contrast specifically; this is the global overlay.

## Notes

Tap-outside-to-close already works (Radix Dialog default). No code change there; just visual overlay strength.
