## Description

src/lib/firebase.ts imports getAuth, initializeFirestore, getFunctions, getStorage — all four Firebase modules. Plus 41 source files import directly from 'firebase/firestore' / 'firebase/auth' / 'firebase/storage' / 'firebase/functions'.

Storage is only needed when uploading images (notes/chat). Functions is only needed when sending OTP / specific server calls. Firestore is needed on chat/notes pages. Auth alone is needed at boot.

Current setup forces the entire Firebase JS SDK into the critical-path bundle.

## Steps to reproduce

1. Inspect src/lib/firebase.ts
2. grep -r firebase/ Wedding-Ease-Viva-Chat/src | wc -l

## Expected

Auth loaded eagerly. Firestore loaded when first chat/notes route renders. Storage + Functions loaded lazily at first use.

## Actual

All four Firebase product modules bundled into the initial JS.
