## Description

```ts
const initial = useMemo(
  () => profile?.toneSettings ?? DEFAULT_TONE,
  [profile?.toneSettings],
)
```

`profile` is the frozen AuthContext profile. If the user edits tone in Tab A, Tab B's AiBehaviorTab `initial` reference never recomputes — sliders show stale starting positions. Edits in Tab B will overwrite Tab A's saved tones with the pre-Tab-A baseline. Lost-update scenario.

## Steps to reproduce

1. Tab A and Tab B open at Settings → AI Behavior.
2. Tab A: set Warm=80 → Save.
3. Tab B (without reload): observe initial slider positions.

## Expected

Tab B's sliders re-render with Warm=80.

## Actual

Tab B's sliders remain at the pre-A values. Saving in Tab B reverts Warm to whatever Tab B started at.
