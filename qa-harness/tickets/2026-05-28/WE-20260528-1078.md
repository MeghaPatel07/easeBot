## Description

Per the existing Sprint-1 ticket WE-20260528-064 (payment-failure-reason-unknown UX copy), the payment failure page is a generic "Payment failed" page with no:
- Specific reason from PayU (card declined / 3DS failed / insufficient funds / bank timeout)
- Next-action ("Try a different card?", "Wait 5 minutes and retry?")
- Help link (3.2.6 fail)
- Contact support email / phone visible

For users with cognitive impairments, payment failures are doubly distressing — the lack of explanation triggers anxiety AND can lock them out of the upgrade flow.

## Expected

- Surface the PayU error code translated to plain language ("Your card was declined by your bank")
- Up to 3 next-action buttons: "Try again", "Use a different card", "Contact support"
- Persistent Help link in page chrome (3.2.6)
- Reference: PayU error code → plain-English mapping table

## Actual

Generic "Payment failed" + Retry button.

## Notes

Combines -064 + -1058 (generic errors) + -1059 (consistent help). High priority because payment-failure is a moment of cognitive load.
