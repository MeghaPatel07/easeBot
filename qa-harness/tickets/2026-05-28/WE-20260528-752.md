## Description
Planner ROUTING RULES (planner.ts:77-83) lists 6 branches: REMINDER, CHECKLIST, NOTE, NOTE APPEND, TIMELINE EVENT, NORMAL. None of them say "if the user asks a styling question, hand off to stylist." Branch 6 (NORMAL) is the catch-all and says "reply with text only" — so a styling question gets answered with planner's voice and tooling (timelines, checklists), not the stylist's aesthetic vocabulary or product catalogue access. The user loses access to the product catalogue context (`productsContext` is only injected into the stylist prompt at stylist.ts:169-178) when stuck in planner.

## Steps to reproduce
1. Pin planner mode.
2. Send "what should the bride wear for a Bangalore beach mehndi?"
3. Planner replies with a stripped-down list (no styling vocabulary, no catalogue products), because Algolia/product-catalogue injection is gated by stylist mode.

## Expected
Add a routing rule to planner.ts ROUTING RULES: "STYLIST HAND-OFF: If the user's question is about attire/colors/aesthetics/jewellery and not about scheduling, say 'let me bring in the stylist perspective' and either inline the stylist guidance or re-route." OR add a stylist re-classifier to modeRouter.ts that activates within a pinned-planner thread.

## Actual
Planner answers stylistically with no product catalogue. User has to manually toggle modes — bad UX.

## Notes
Sibling: WE-20260528-751. Both reflect a missing cross-mode hand-off pattern. Cheaper fix: add a "if your answer would be more authoritative in another mode, mention it in-line" clause to all 4 mode prompts.
