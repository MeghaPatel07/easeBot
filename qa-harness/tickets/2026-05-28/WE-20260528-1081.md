## Description

Resend countdown shown as: "Resend code in <span>{fpResendTimer}s</span>". The countdown updates every second visually — but is plain text not in a live region. SR users:
- Don't hear updates
- Don't know remaining time without manually inspecting
- May submit too late and lose the entry

Same applies to OTP expiry countdown (separate `otpExpiryTimer`).

## Expected

- Wrap critical countdowns at < 30s in `<span role="status" aria-live="polite">` so SR users hear "30 seconds remaining... 20 seconds... 10 seconds"
- Don't blast every second — debounce to 30s, 10s, 5s, 0s milestones
- Provide an "I need more time" button as 2.2.1 spec requires

## Actual

Visual-only timer; SR silent.

## Notes

Pairs with -1061 (5-min OTP overall) — this is the SR-specific complement.
