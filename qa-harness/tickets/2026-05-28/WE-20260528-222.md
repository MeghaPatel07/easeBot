## Description

`threadId: z.string().optional()` — no length cap, no UUID format check, no allowlist.

This pairs with the WE-20260528-202 finding (`requireAuth` silently passes anonymous): if `getChatHistory(threadId, uid)` doesn't strictly enforce `thread.ownerUid === uid` before returning history, then ANY caller could read another user's thread by guessing its ID. I did NOT probe this path with real IDs.

Recommend:
1. `threadId: z.string().uuid().optional()` to force a known shape.
2. Defense in depth: explicit ownership check in `getChatHistory`. (Filed as a separate concern — please verify ownership enforcement.)
