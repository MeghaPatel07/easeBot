## Description

`new Audio(audioUrl); audio.play().catch(...)` — voice preview starts immediately when the user selects a voice. While this is intentional (preview = play), if the modal is opened then closed quickly, the audio may continue playing in the background until the URL is revoked. Also: rapid voice-switch fires multiple plays simultaneously (race).

## Expected

- Cancel previous preview before starting next (`previewAudioRef.current?.pause()`)
- Auto-pause on modal close
- Visible stop button per voice option
- Respect `prefers-reduced-motion` user setting → don't auto-preview, require explicit "Preview" tap

## Actual

Plays on selection, may race, may persist post-close.
