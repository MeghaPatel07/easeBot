## Description

Sprint-1 -282 noted the share modal is a `<div onClick={close}>` with no role/aria-modal. THIS ticket adds the dimension: a switch-control user (1 button) cannot escape the modal at all — they scan through, activate one option, but if they want to dismiss without choosing, there's no "Close" button accessibly named (verify ImageActions.tsx render path), and the Esc-key escape (which Radix would provide) is absent.

For motor-impaired users on a single switch, this is a hard trap.

## Expected

Per -282 fix: migrate to Radix Dialog. As a fast patch in the interim: add a focus-trap, Esc handler, AND a visible Close button with `aria-label="Close share dialog"`.

## Actual

Click-outside dismisses; no key-based exit.
