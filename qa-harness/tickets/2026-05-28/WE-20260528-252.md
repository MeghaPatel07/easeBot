## Description

The "Decline" button uses `text-foreground/50` on a translucent `bg-background/95` panel. Axe flags this on every scanned page (home, pricing, terms, privacy, help, login, notfound — 7 of 7 pages) as a serious color-contrast violation. Decline is a meaningful choice; users with low vision should be able to read it.

## Steps to reproduce

1. Clear localStorage `ph_consent`.
2. Open any page — banner appears bottom-center.
3. Inspect Decline button contrast.

## Expected

≥ 4.5:1 against banner background.

## Actual

`text-foreground/50` (~50% opacity foreground) on `bg-background/95` — measured below 4.5:1 by Axe in both light and dark modes.

## Evidence

- `qa-harness/evidence/a11y-2026-05-28/home/axe.json` — color-contrast violation, 2 nodes.
- Repeats on `/pricing`, `/terms`, `/privacy`, `/help`, `/login`, `/this-page-does-not-exist`.

## Notes

Suggested: use `text-foreground/75` (or `text-foreground`) for the button text; `text-foreground/50` is fine for hints, not interactive labels.
