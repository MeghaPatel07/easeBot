## Description

The currency selector is wrapped in `<label>` which provides programmatic association, but the label text "Currency" is not displayed (no visible text); users see only "USD/INR/EUR…". The select is 62×36px, below 44×44px touch target. Screen reader users do hear "Currency" because of the wrapping label, but sighted users (especially first-time visitors) must infer purpose from the option values alone.

## Steps to reproduce

1. Open `/pricing` at mobile breakpoint.
2. Try to identify what the dropdown next to the price toggles changes.

## Expected

Visible label "Currency" or icon + label combo. Touch target ≥ 44px height.

## Actual

Naked dropdown, no visible affordance.
