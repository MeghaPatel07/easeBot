## Steps to reproduce
1. App.tsx:53, `const queryClient = new QueryClient()` with no options.
2. Defaults pulled from TanStack v5: `refetchOnWindowFocus: true`, `refetchOnReconnect: true`, `networkMode: 'online'`, `retry: 3`, `staleTime: 0`.
3. Audit `package.json`, currently `@tanstack/react-query ^5.x`. A future minor bump could change defaults.

## Expected
Explicit `defaultOptions` for queries + mutations, especially:
```ts
new QueryClient({
  defaultOptions: {
    queries: {
      refetchOnReconnect: 'always',
      refetchOnWindowFocus: 'always',
      networkMode: 'online',
      staleTime: 30_000,
      retry: 2,
    },
    mutations: {
      networkMode: 'always', // so optimistic mutations queue offline
      retry: 0,
    },
  },
})
```

## Actual
- All implicit; brittle.
- Combined with the other tickets in this sprint (951, 952, 958), this is the foundation that needs to land first.
