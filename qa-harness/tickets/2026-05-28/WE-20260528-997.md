## Steps to reproduce
1. Open chat. Mode = "chat". Send button shows arrow.
2. Switch mode to "image". Placeholder updates to "Describe an image". Button icon expected to switch to camera icon.
3. Observe send button without typing.

## Expected
Icon updates immediately.

## Actual
- Placeholder re-renders (it reads `activeMode` directly). But the send button uses a memo/icon prop pinned to `mode` prop passed at parent level, depends on parent re-render which only happens on input change.
