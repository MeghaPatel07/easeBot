## Description

vite.config.ts has only 'build: { sourcemap: false }' — no rollupOptions.output.manualChunks, no chunkSizeWarningLimit override, no build.target. Without manualChunks, Vite/Rollup uses default chunking which puts all node_modules dependencies into a single chunk (the 1.2MB index-*.js).

Build output confirms this: '(!) Some chunks are larger than 500 kB after minification. Consider: ... Use build.rollupOptions.output.manualChunks to improve chunking.'

## Steps to reproduce

1. cat Wedding-Ease-Viva-Chat/vite.config.ts

## Expected

manualChunks configured to split:
  - react vendor (react, react-dom, react-router-dom, @tanstack/react-query)
  - tiptap (@tiptap/*)
  - firebase (firebase/*)
  - radix (@radix-ui/*)
  - analytics (posthog-js)

## Actual

No manualChunks; everything in one vendor chunk.
