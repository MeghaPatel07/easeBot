## Description

`SidebarMenuSkeleton` (line 646-682) sets `--skeleton-width` via React state initialized from `Math.random()` per row, to make the skeleton bars look natural (different widths). However:
- The width is recomputed on every render of the parent.
- During hot-reload or React StrictMode double-invoke, widths flicker visibly.
- On slow connections where the skeleton stays for >2s, the rerender from a parent state change (e.g. theme toggle) jitters all skeleton widths.

The fix is to memoize the random value with `useMemo(() => Math.floor(Math.random() * 40) + 50, [])` (empty deps), or pre-compute a stable seed from the row index.

## Steps to reproduce

1. Open /chat with the sidebar open.
2. DevTools → Network → Slow 3G.
3. Reload — observe skeleton rows.
4. Toggle theme (Cmd+Shift+T or wherever the theme toggle is) — observe skeleton widths jitter.

## Expected

Stable width per row across re-renders.

## Actual

Width flickers on re-render.
