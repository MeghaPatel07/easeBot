## Description

Help/feedback form likely re-asks for name + email on every submission for guest users. WCAG 2.2 3.3.7 explicitly requires that within a multi-step process OR for repeated visits to the same form, info previously entered should be auto-populated OR available for re-selection. Logged-in users already have name+email — should be auto-filled. Guests should at minimum have `autocomplete="name"` / `autocomplete="email"` so the browser can offer.

## Expected

- Logged-in: prefill from `user.displayName` + `user.email`
- Guest: `autoComplete="name"`, `autoComplete="email"`

Need to verify in Help.tsx — high probability all manual.
