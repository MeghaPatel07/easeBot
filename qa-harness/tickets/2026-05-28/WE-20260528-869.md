## Description

SettingsShell on mobile (<768px) renders a list-of-tabs view; selecting a tab swaps to its content with a top-left "Back" button using lucide `ArrowLeft`. In LTR locales that's correct. In RTL (Arabic) the back button should point to the right (toward where the previous view conceptually "lives"). Without flipping, RTL users may mis-perceive the button as "forward."

## Steps to reproduce

1. Resize to mobile (375 width).
2. Open Settings.
3. Click any tab — observe the "Back" button at top-left with `ArrowLeft` pointing left.
4. Set `document.documentElement.dir = 'rtl'`; the button is still left-pointing.

## Expected

Apply `rtl:-scale-x-100` to the icon, OR swap to `ArrowRight` programmatically when `dir === 'rtl'`.

## Actual

Static `ArrowLeft` regardless of direction.

## Evidence

- SettingsShell.tsx:31 (import of `ArrowLeft`).
