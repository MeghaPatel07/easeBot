## Steps to reproduce
1. Free tier user with 2 reminders (cap=3).
2. Open Settings, change nickname, click Save.
3. Immediately open Reminders, create a 3rd reminder before the Save resolves.

## Expected
Both operations succeed independently.

## Actual
- `createReminder` runs `getDocs(query(remindersCol(user.uid), where('status','==','pending')))` to count pending. The count returns 2, allows. OK.
- But the call also receives `profile` as a snapshot from caller. If `profile` has changed between when caller captured it and the count returned, tier may be misread (rare but possible during upgrade flow).

## Suggested owner
fix-state-data
