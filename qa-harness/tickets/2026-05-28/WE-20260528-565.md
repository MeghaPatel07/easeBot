## Steps to reproduce
1. Tab A: open the image generation composer. Set aspect ratio to 16:9.
2. Tab B: also has the composer open (default 1:1, the React state was initialized on mount).
3. In tab A, the value writes to `localStorage.easebot-image-aspect-ratio = '16:9'`.
4. In tab B, generate an image.

## Expected
Tab B uses the user's most recent aspect ratio choice (16:9).

## Actual
Tab B uses 1:1 — the ratio it had at its initial render. No `storage` listener, no React-re-read on focus.

## Impact
P2 — wrong-shape image; user clicks regen, costs a token. Compounds with the token meter to feel like the app is buggy and burning their quota.

## Fix direction
Add `storage` listener to `VibeComposer.tsx` mirroring the localStorage value into React state.
