## Description

Summarization is triggered when `history.length > 10`:
```ts
if (history.length > 10) {
  const olderMessages = history.slice(0, history.length - 5)
  const recentMessages = history.slice(history.length - 5)
  const summary = await summarizeConversation(olderMessages, getClient(), targetLanguage)
  effectiveHistory = [
    { role: 'assistant' as const, content: `[Previous conversation summary]: ${summary}` },
    ...recentMessages,
  ]
}
```

But `history` comes from `getChatHistory` which always pulls the last `historyLimit = 10` messages from Firestore — so `history.length` is at most 10. The summarizer never fires from the Firestore-path of getChatHistory.

It DOES fire when the client sends in-body `history`: `providedHistory.slice(-historyLimit)` returns up to 10. So when does `> 10` happen? Only when the client sends a `history` larger than 10 AND no `threadId`. Per `getChatHistory`:
```ts
if (!threadId && providedHistory && providedHistory.length > 0) {
  return providedHistory.slice(-historyLimit)  // returns ≤10
}
```

So `history` is ALWAYS ≤10 after `getChatHistory`. The summarizer never fires in practice. Dead code path masquerading as a cost-control feature.

If the threshold were raised (or `historyLimit` was raised), the current implementation would summarize the SAME `slice(0, -5)` block on every turn — paying the summarizer LLM cost (max_tokens=300, ~1k prompt tokens) for the same output every time. There's no summary cache keyed on the prefix hash.

## Expected

- Bump `historyLimit` in getChatHistory to e.g. 40, so the > 10 branch can actually fire.
- Cache the summary on the thread doc: `chats/{threadId}.summary` + `chats/{threadId}.summarizedUpToMessageId`. On each turn, summarize only the gap between `summarizedUpToMessageId` and `len - 5`.
- For in-body history (anonymous / guest), key the cache on a hash of `olderMessages` content.

## Cost impact

Every long-thread chat turn pays for a fresh ~1300-token summarizer LLM call. For a pro user with a 50-turn thread, that's ~65K tokens/conversation wasted on duplicated summarizations.
