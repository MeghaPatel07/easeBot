## Description

WeddingEaseFloater is bottom-right fixed (16/14 sm/md size). On mobile, when a focusable element is near the bottom-right corner (e.g. share button on a chat message), the floater can cover the focused element entirely. Sprint-1 -070 covered the FAQ chevron obscured case; this is the general pattern.

Also: the floater itself is interactive ("draggable={false}" present but the link/anchor wrapping might not have an accessible name — verify).

## Expected

- `scroll-padding-bottom` on body equal to floater height + margin
- Floater itself: explicit `aria-label="Open WeddingEase home"` or similar
- Consider hiding floater on small viewports for chat-bearing surfaces

## Actual

Floater can obscure low-right focus targets on mobile.

Pair with -070 + -1083 for the consolidated "fixed elements obscuring focus" fix.
