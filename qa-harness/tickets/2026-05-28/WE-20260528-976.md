## Steps to reproduce
1. Send 2 chat messages.
2. Switch mode to "image". Send an image message.
3. Switch back to chat. Send another message.
4. Observe bubble styling on all 4 message exchanges.

## Expected
Each message keeps the styling of the mode it was sent under (correct historical record).

## Actual
- Each message has its `mode` set at send-time (good). But the active mode at render time is also read via context — some style-conditional checks in ChatMessages mistakenly read `activeMode` instead of `message.mode`, causing already-rendered bubbles to flicker style when the user switches mode.
