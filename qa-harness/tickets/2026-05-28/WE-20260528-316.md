## Description

src/pages/Index.tsx (1668 lines) contains 172 arrow functions and only 3 useCallback calls. JSX in the main render path passes new function identities to child components on every render. Examples (lines 1436-1465):

ChatMessages receives onToggleProductLike={(product) => { ... track(...); toggleProductLike(...); }}, onShareProduct={async (productTitle) => { ... }}, onRequestMoreProducts={() => { ... }}, onOpenPlanner={(checklistId) => { ... }}, onShowSignIn={() => setShowSignInModal(true)} — all inline arrow functions, all new on every render.

Also: line 1369 const inputBarProps = { ... 13 fields ... } — recreated every render, then spread into TWO ChatInput instances (lines 1488, 1647).

## Steps to reproduce

1. Open src/pages/Index.tsx and grep '=>' (172 matches)
2. Open React DevTools Profiler, type a single character into the chat input
3. Observe Index → ChatHeader, ChatMessages, ChatInput all re-render

## Expected

Stable callback identities via useCallback; props objects via useMemo.

## Actual

Every parent render recreates ~30 callbacks and the inputBarProps object, forcing cascading child re-renders.
