## Description

Every audited route returns `document.title === "TheWeddingBot - Your Personal Wedding Planning Assistant"`. This is the static `<title>` from `index.html` — no React Helmet or router-driven title updates. SR users using multi-tab workflows cannot tell tabs apart; screen-reader announcement of page change is generic.

## Expected

Per-route title: "Pricing · TheWeddingBot", "Terms of Service · TheWeddingBot", "Help & Feedback · TheWeddingBot", "Sign in · TheWeddingBot", "Page not found · TheWeddingBot", etc.

## Notes

Already partially considered for SEO via `useCanonical` hook — extend with `useDocumentTitle` similar pattern.
