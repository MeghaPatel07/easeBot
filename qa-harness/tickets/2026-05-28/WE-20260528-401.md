## Description

`useVoice` was migrated to a "ChatGPT-style record-then-transcribe" model — see the file-level comment at `useVoice.ts:36-39`:

> Unlike the previous live-streaming implementation, we do NOT surface interim text to the UI. The textarea stays untouched during recording; only after transcription completes do we return the final transcript in one shot.

The returned `interimText` is hard-coded to `''` (`useVoice.ts:315 — "interimText: ''"`), and `UseVoiceResult.interimText` keeps the field "Always empty now — no live interim text. Kept so callers don't break."

PRD-TTS-Pipeline.md §6 (the inbound/outbound comparison table) and §10 still claim STT does **"Yes (interim results shown live)"** streaming. The doc is now stale; the product no longer matches the contract Krish published. Sprint 2 brief explicitly calls this out as a focus area ("interim transcription UX").

## Steps to reproduce

1. Read `PRD-TTS-Pipeline.md` §6, row "Streaming" — STT column reads "Yes (interim results shown live)".
2. Open `Wedding-Ease-Viva-Chat/src/hooks/useVoice.ts:36-39` — comment explicitly says interim is no longer surfaced.
3. Grep `interimText` callers — `ChatInput.tsx:255` destructures it, but the field is always empty.
4. Run the app and tap the mic — the textarea stays empty for the entire recording duration; no "I want to plan a beach…" partial text ever appears.

## Expected

Either:
- Restore live interim STT (Azure Speech SDK supports `recognizing` event for partials) and keep the PRD accurate, OR
- Update PRD-TTS-Pipeline.md §6 + §10 to reflect the record-then-transcribe model and remove all "interim" references.

## Actual

PRD says one thing; code does the other. Users who expected live captions (e.g. for accessibility) get nothing during recording.

## Evidence

- Source: `Wedding-Ease-Viva-Chat/src/hooks/useVoice.ts:36-39` (comment), `:315` (hard-coded `''`).
- Spec: `PRD-TTS-Pipeline.md` line 351 (table row).

## Notes

Tradeoff is intentional (mobile mic flakiness, simpler UI), but it leaves the doc/spec contract broken. Cheapest fix is docs, not code.
