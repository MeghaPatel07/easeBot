## Description

Per the system prompt + WE-20260527-350, planner mode is supposed to surface "max 3-5 checklist items" per response. Live planner mode dumps 15 numbered items across 3 H3 sections in a single response (over 1200 chars, 24 lines). This was filed yesterday as WE-20260527-350 and is still reproducible today — same root cause, no fix landed yet. Filed again to confirm regression / no-progress, NOT as a duplicate (today's evidence is fresh).

Verified prompt: "Make me a 3-month wedding planner" with `mode: 'planner'`.

## Steps to reproduce

```
curl -sS -X POST http://localhost:3001/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"Make me a 3-month wedding planner","mode":"planner"}' \
  --max-time 20 | python3 -m json.tool
```

→ 15 numbered items, 3 sections — 3× the documented cap.

## Expected

- Planner returns 3-5 actionable items max per message OR proposes one section at a time.
- If user asks for the full plan, planner OFFERS to break it into messages.

## Actual

Full 3-month plan delivered in a single 24-line message. User cannot tell which items are highest priority.
