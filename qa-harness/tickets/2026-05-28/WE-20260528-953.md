## Steps to reproduce
1. DevTools, Network, throttle to "Slow 3G".
2. Send a message.
3. User bubble appears immediately. The "typing" indicator shows. SSE stream begins very slowly.
4. After ~5s with no visible AI text yet, user assumes click was lost and clicks Send again.

## Expected
- Either Send button is disabled while `isTyping === true` (guard exists at useChat.ts:348 — `if (isTyping) return`), OR there is a visible "still thinking" indicator with elapsed time.

## Actual
- Guard works at hook level (second call returns early), but the ChatInput UI does not disable / dim the input area visibly. User types a second message into the same input; on send it is swallowed silently with no feedback.
- No "your message is taking longer than usual" copy after N seconds.
- Slow-3G SSE first-token can take 8-15s; user gets no progress signal.

## Suggested owner
fix-state-data + fix-state-ui
