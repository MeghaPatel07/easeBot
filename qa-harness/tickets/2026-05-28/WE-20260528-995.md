1. Sign in. Set theme dark. Backend has dark.
2. Go offline. Toggle theme to light. UI flips light immediately (optimistic).

4. Reload (back online). useAccount loads, profile.preferences.theme = dark, ThemeProvider effect at line 78-85 sees mismatch, flips back to dark.
