## Description

These confirmation pages render directly inside a generic `<div>` with no `<header>`, `<main>`, `<nav>`, or `<footer>` — landmarks count = 0/0/0/0. Screen-reader users land on the page after a redirect from PayU and have no rotor structure to navigate. Critical given these pages convey transaction outcome (success/failure) which can affect billing decisions.

## Steps to reproduce

1. Open `/payment/success?tier=pro`.
2. Open VO Rotor → Landmarks.

## Expected

`<main>` wrapping outcome content, optional `<header>` with logo, `<footer>` if links present.

## Actual

Zero landmarks.

`qa-harness/evidence/a11y-2026-05-28/_extra.json` → `payment-success.landmarks` and `payment-failure.landmarks` all zero.
