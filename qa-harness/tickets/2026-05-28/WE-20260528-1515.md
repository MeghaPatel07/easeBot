# WE-20260528-1515 — express.json limit 20mb mounted globally — every request allocates parser for image uploads

**Severity:** P3
**Status:** triaged
**Assigned:** fix-performance
**Area:** Performance / Express middleware
**Discovered:** 2026-05-28

## Symptom
`app.ts:60` mounts `express.json({ limit: '20mb' })` at the app level. Every request -- `/api/health`, `/api/chat`, `/api/payment/return` -- goes through a JSON parser configured for 20MB payloads. Only the image upload endpoint actually needs the 20MB cap.

## Why this matters
- For typical small JSON requests (`/api/chat` text-only ~5KB), the buffer pre-allocation is harmless.
- For OPTIONS preflights and health checks, the middleware still mounts.
- The bigger issue: a malicious client could send 20MB to ANY endpoint and tie up the parser. Not a hot perf path, but a DoS vector.

## Suggested fix
Default small limit globally (256kb), larger limit only on routes that need it:
- `app.use(express.json({ limit: '256kb' }))`
- `app.use('/api/generate-image', express.json({ limit: '20mb' }))`
