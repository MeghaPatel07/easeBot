## Description

Mode-switch button row uses `transition-all duration-300` and `transition-colors`. While the global reduced-motion reset clamps duration to 0.01ms (effectively a snap), individual class chains like the mode-highlight pill (`active: 'bg-primary text-primary-foreground shadow-sm'` with implicit fade) leave behind brief flashes. Combined with the page-level mode switch (color theme accent shifts), users sensitive to motion experience screen-color shifts.

## Expected

Audit mode-switch + color-accent updates under `prefers-reduced-motion: reduce`:
- Use `motion-reduce:transition-none` on accent transitions
- Avoid simultaneous large-area color shifts

## Actual

Subtle but present color flash on mode change.
