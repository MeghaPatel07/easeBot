## Description

Password meter uses `{met ? '✓' : ''}` rendered inline. SR announces:
- When met: "check mark, At least 12 characters"
- When not: "blank, At least 12 characters"

As the user types, the meter dynamically updates — SR may announce "check mark, check mark, check mark" rapid-fire as multiple requirements flip. No `aria-live` boundary, no `role="status"` wrapper to throttle.

## Expected

- Hide `✓` from SR via `aria-hidden="true"` span; provide explicit "Met:" / "Not met:" prefix via `<span class="sr-only">`
- Wrap the requirements list in `role="status" aria-live="polite"` so updates are announced once-per-debounce, not per-character

## Actual

Symbol noise + uncontrolled chatter under fast typing.

## Notes

P3 because impact is limited to active password creation — but extreme during that moment.
