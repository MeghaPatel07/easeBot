## Description

Sprint 2 ticket -457 documented the absence of any `@media print` stylesheet for `/privacy`, `/terms`, `/help`. That ticket scoped only those legal/marketing pages.

But the two pages that users are **most likely** to print are:
1. **SharedChat** — a wedding planner shares an entire AI-conversation thread with their client; the client wants to save the transcript as PDF.
2. **SharedNote** — a planner exports a single note (vendor checklist, ceremony script, vow ideas) to PDF for offline reference.

Both these pages render with:
- Full app background gradient (decorative pink mosaic).
- WeddingEaseFloater button (decorative).
- The "Continue planning with WeddingEase" CTA banner.
- AnalyticsConsent banner (if dismissed → no, but if not dismissed → yes).
- Sticky page header with "Sign up" CTA.

When printed (Cmd+P), the resulting PDF wastes ink on backgrounds + crops the actual transcript because no `page-break-inside: avoid` on message bubbles → bubbles split across pages mid-sentence.

## Steps to reproduce

1. Open any `/share/:token` URL with >5 messages.
2. Cmd+P (or DevTools → Rendering → Emulate CSS media `print`).
3. Observe: gradient background, floater, CTA banner all present; message bubbles split across page breaks.

## Expected

Add a `@media print` block scoped for `.shared-chat-surface` / `.shared-note-surface`:
- `.app-decorative-bg, .floater, .analytics-consent, .signup-cta { display: none !important }`
- `body { background: white; color: black }`
- `.message-bubble { page-break-inside: avoid; break-inside: avoid }`
- `h1, h2 { page-break-after: avoid }`
- Show sender + timestamp inline above each bubble (currently visually present but visually relies on color contrast that may disappear in BW print).

## Actual

Bare-web print, messy PDFs, often unusable as a vendor handoff.

## Evidence

- `grep -rn "@media print" src/` → zero matches.
- `grep -rn "print:" src/` (Tailwind print: utility) → zero matches.

Companion to Sprint 2 -457. That ticket scoped legal/help pages; this scopes shared-link export — arguably the higher-value print target.
