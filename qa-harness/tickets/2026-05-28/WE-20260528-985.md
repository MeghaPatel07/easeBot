## Steps to reproduce
1. Tab A: open /notes/abc, type 1 paragraph.
2. Tab B: open /notes/abc, sees the original (no live sync), type a different paragraph.
3. Tab A: Save.
4. Tab B: Save.

## Expected
Some merge/conflict UI, or "another tab edited this, refresh?".

## Actual
- Last-writer-wins. Tab A's content lost without warning.
- No version field, no etag, no `updatedAt` precondition check on the write.

## Severity rationale
P0, silent data loss is the worst class of state-sync bug.
