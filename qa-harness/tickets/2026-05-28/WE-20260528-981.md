## Steps to reproduce
1. Type to assistant: "remind me to call the florist next Friday at 10am".
2. Backend tool creates a reminder doc.
3. Open CalendarView immediately.

## Expected
New reminder visible in calendar within 1s.

## Actual
- CalendarView depends on `refetchReminders` to update. Tool-call writes via assistant but does not trigger frontend refetch — the next refetch tick (or page nav) reveals it.
- `subscribeToReminders` IS used in `useKnownArtifactIds` but the calendar consumer is a separate hook that does one-shot.
