## Description

Voice control resolves "Click X" by visible or accessible name. Across the app multiple buttons are labeled "Send" (chat composer Send icon, OTP "Send Verification Code", InvitePartner "Send invite", share "Send link"). When a voice-control user has the InvitePartner dialog open over chat, "Click Send" is ambiguous — Voice Control may pick the chat composer instead of the dialog send.

Same for "Cancel", "Back", "Close", "Save" — generic verbs proliferate.

## Expected

Disambiguate via unique aria-labels: "Send chat message", "Send verification code", "Send invite to partner", "Close share dialog", "Cancel checkout" — including the noun.

## Actual

Generic single-verb names create voice ambiguity.

## Notes

Lower severity P2 because keyboard + screen-reader users navigate sequentially, only voice-control / switch-grid users are affected. But the fix (richer aria-labels) helps SR users too — currently they hear "Send button" with no context after switching apps.
