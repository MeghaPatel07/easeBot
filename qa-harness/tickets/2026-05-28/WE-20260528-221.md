## Description

`language: z.string().max(10).optional()` — accepts any ≤10-char string. A caller can submit `language: "BOMBASTIC"` and downstream code that branches on language will either no-op silently or hit an unexpected else branch. If the language string is concatenated into the LLM system prompt anywhere (e.g. "respond in ${language}") it becomes a prompt-injection vector for short strings.

## Steps to reproduce

```bash
curl -s -X POST http://localhost:3001/api/chat -H "Content-Type: application/json" \
  -d '{"message":"hi","language":"prompt"}'  # 'prompt' is ≤10 chars
```

## Expected

```ts
language: z.string().regex(/^[a-z]{2}(-[A-Z]{2})?$/).optional(),
```

OR an explicit enum of supported languages (`en`, `es`, `ar`, `he`, `hi`, `fr`, `de`, ...).

## Actual

Free-form ≤10-char string accepted.
