## Description

When image generation completes, the ImageCarousel mounts inline in the assistant message. Two problems:

1. The mount itself does not announce — even if the parent message bubble were inside a `role="log"` region, the carousel is wrapped in a `<div>` (not `<figure>` with `<figcaption>`), so SR users get no signal "image arrived".
2. The alt text on the carousel's `<img>` is generic (`'AI-generated image'`) per WE-20260527-258. Even if the announcement fires, no useful description is conveyed.

Net: after the silent generation period, the user has no way to know an image arrived OR what it looks like, even though the original prompt was theirs.

## Steps to reproduce

1. SR on, image mode
2. Send "make me a temple wedding mandap photo"
3. Wait — image arrives — silence

## Expected

On settle: live region announces "Image generated: {echo of prompt}". `<img alt>` reflects the original prompt verbatim.

## Actual

No completion announcement. Generic alt.

## Notes

Pair with -652 (in-progress announcement). On settle, emit a `<span role="status">` like "Generated image — {message.text}". Verify ImageCarousel's `<img>` reads `alt={prompt}` not `alt="AI-generated image"`.
