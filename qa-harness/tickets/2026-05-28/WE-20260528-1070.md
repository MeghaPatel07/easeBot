## Description

App supports 10 languages on the chat side (Hindi, Gujarati, Spanish, French, Arabic, Portuguese, German, Chinese, English, auto-detect — `constants.ts:9-20`). However:
- All UI chrome (buttons, headings, hero text, FAQ Q&A, Privacy Policy, Terms of Service) is in English only
- For a non-English speaker, the user can chat in their language but cannot read the surrounding UI to operate it
- Specifically: a user who only reads Arabic cannot understand "Sign up", "Pricing", "Settings", "Help" — all monolingual

For users at the intersection of language + cognitive accessibility, this is a primary blocker.

## Expected

i18n the UI chrome — at minimum Hindi + Gujarati for the Indian market, given the wedding planning context.

## Actual

UI English-only, content i18n only.

## Notes

Out of scope for an a11y *fix*, but the a11y *implication* is real: lang detection only on chat content means the rest of the page sets a hostile context for non-English users. File for product/i18n roadmap.
