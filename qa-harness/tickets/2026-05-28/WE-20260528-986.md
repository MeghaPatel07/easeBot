## Steps to reproduce
1. Brand-new user, fresh sign-in. Onboarding modal shows.
2. Tab A, complete onboarding. Modal dismissed; profile.onboardingCompleted = true (Firestore).
3. Open Tab B (same user, new tab).

## Expected
No modal. Onboarding is done.

## Actual
- Tab B's AuthContext calls `getDoc` fresh, sees `onboardingCompleted: true`. OK in this case.
- BUT if Tab B was already open at the time Tab A completed onboarding, Tab B's profile is the old one and modal re-appears next time it triggers.

## Suggested owner
fix-state-data
