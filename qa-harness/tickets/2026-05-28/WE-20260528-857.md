## Description

Loading-states are wildly inconsistent across the app. The shared `<Skeleton>` component exists at `src/components/ui/skeleton.tsx` and `SidebarMenuSkeleton` uses it correctly in the chat sidebar — but **literally no other view uses the Skeleton pattern**. Audit:

| Surface | Loading affordance |
|---|---|
| GalleryView | Single centered `Loader2` spinner with "Loading gallery…" text |
| NotesView | Single centered `Loader2` spinner |
| BudgetDashboard | None — renders empty/zero numbers until data fetched |
| PlannerView | None — checklists render only after fetch |
| TimelineView | None — entries render only after fetch |
| Settings → Account | None — `useAccount` data flashes from `undefined` (fields empty) to populated |
| Settings → Plan & Billing | None — pricing flashes from default to user's tier |
| ChatSidebar nav items | `SidebarMenuSkeleton` (correct pattern) |
| ChatMessages | typing-bubble shimmer |

The inconsistency means:
- A user clicking through the sidebar (Gallery → Notes → Budget → Planner) sees four different loading affordances in 10 seconds.
- The blank-render flow (Budget, Planner, Timeline, Settings tabs) is jarring CLS — content snaps in after fetch.
- The spinner flow (Gallery, Notes) blocks the whole content area even after the list arrives, until the FIRST image decodes (gallery — covered separately in -854).

## Steps to reproduce

1. DevTools → Network → "Slow 3G".
2. Sign in.
3. Open the sidebar; click Gallery → Notes → Budget → Planner → Timeline → Settings → Account → Plan & Billing.
4. Observe four+ different loading visual languages.

## Expected

Pick one standard:
- For lists with known item-shape (notes, gallery, planner items, budget categories): render N `<Skeleton>` rows with the same vertical rhythm as the real items.
- For Settings tabs: render skeleton rows for each card section.
- Replace the centered-spinner anti-pattern with skeletons everywhere except inline button-pending states (which can keep `Loader2`).

## Actual

Four loading languages, mostly blank-or-spinner.

## Evidence

- `grep -rn "Skeleton" src/` → only `ui/skeleton.tsx`, `ui/sidebar.tsx` (the source and the only consumer).
- Specific files audited above.
