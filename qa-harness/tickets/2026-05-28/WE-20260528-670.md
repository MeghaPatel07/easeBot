## Description

SettingsModal renders Identity/Tone/Voice as a row of buttons with `setActiveTab` toggling the visible panel. Missing ARIA:

- No `role="tablist"` on the wrapping `<div>`
- Each button missing `role="tab" aria-selected="true|false" aria-controls="{panelId}"`
- The visible panel is just `{activeTab === 'identity' && <…>}` — no `role="tabpanel" aria-labelledby`
- No arrow-key navigation between tabs (Left/Right per ARIA Authoring Practices)

SR users hear three identical "button" controls and have to guess which is active. The bg-primary fill is visual-only.

## Steps to reproduce

1. SR on
2. Open Settings
3. Listen as you Tab through Identity/Tone/Voice
4. Hear "button, button, button" with no selection state

## Expected

Use Radix `<Tabs>` primitive (already in repo: ui/tabs.tsx). It comes with tablist/tab/tabpanel semantics + arrow-key nav for free.

## Actual

Bespoke button row.

## Notes

Same pattern likely in /pages/settings/tabs/* — verify each. NotificationsTab, AiBehaviorTab use Radix Tabs (good).
