## Description

User uses macOS Voice Control / Apple Dictation to dictate into composer. Dictation fires character bursts that mutate the textarea value. Simultaneously, if the user has an active streaming assistant reply, both the textarea (user dictation) and the message list (assistant streaming) are mutating in real-time. The SR may attempt to announce both, leading to competing live regions.

Per useChat.ts STT/voice pipeline, the recording state has its own placeholder ("Recording...", "Transcribing...") — but these are placeholder-only and disappear once transcription returns.

## Expected

- Pause assistant streaming SR announcement while user is dictating
- Use a single dedicated live-region per modality
- Announce transcription milestones: "Transcribing... done. Your message: 'Plan a Goa wedding'"

## Actual

Two concurrent ARIA live regions can both fire, causing announcement collisions.

## Notes

Edge but realistic for power voice-control users.
