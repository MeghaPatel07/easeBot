## Description

`animate-ping` is an infinite expanding-ring animation that draws continuous attention near the bottom-right of the viewport. The global `prefers-reduced-motion: reduce` rule in `index.css` does set `animation-duration: 0.01ms !important` which effectively kills the visual — verified the rule catches it. Filing as P3 because (a) the animation IS suppressed under reduced-motion, and (b) WE-20260528-255 already proposes removing the floater since the link is non-functional.

## Notes

Will resolve when WE-20260528-255 lands (remove or fix the floater). Until then, motion-sensitive users may find the constant ping distracting if reduced-motion isn't set system-wide.
