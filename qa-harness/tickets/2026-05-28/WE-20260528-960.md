## Steps to reproduce
1. DevTools, Application, IndexedDB. Observe.
2. Reload the app fresh. Inspect again.

## Expected
Either Firestore offline persistence is explicitly enabled (so cached reads work offline) or explicitly disabled with a fallback strategy.

## Actual
- Firestore SDK auto-creates an IDB store (`firestore/...`) for internal use, but `enableIndexedDbPersistence(db)` / `enableMultiTabIndexedDbPersistence(db)` is never called in `src/config/firebase.ts` (grep confirms 0 matches in `src/`).
- Result: queries do NOT serve from IDB when offline — they throw. Listeners do auto-reconnect once back online, but `getDoc` / `getDocs` calls (used in AuthContext, reminderService limit-check, accountService) fail.
- No app-level IDB usage either (no drafts, no offline queue).

## Root cause
Missing Firestore persistence config + missing offline strategy.
