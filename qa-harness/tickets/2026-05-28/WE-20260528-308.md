## Description

index.html has two <link rel='stylesheet'> tags pointing at fonts.googleapis.com/css2 — one for Noto Serif + Inter (898ms wasted per Lighthouse), one for Material Symbols Outlined (178ms wasted). Combined render-blocking time = 1076ms.

These block CSSOM construction and therefore first paint. The fonts have display=swap which helps FOIT but the stylesheet itself still blocks rendering.

## Steps to reproduce

1. Open index.html
2. Run lighthouse render-blocking-resources audit

## Expected

Fonts preloaded with rel='preload' as='style' + onload swap, or self-hosted, or inlined critical subset CSS.

## Actual

Two render-blocking <link rel='stylesheet'> calls to fonts.googleapis.com totaling 1076ms wasted time. Plus the followup .woff2 files load only after CSS is parsed.

## Evidence

- Lighthouse JSON: `qa-harness/evidence/perf-2026-05-28/lh-*-prod.json`
- Build log: `/tmp/perf-build.log`
- Screenshot: `qa-harness/evidence/perf-2026-05-28/*.jpg`

## Notes

Fix pattern (Vercel rule): <link rel='preload' as='style' href='...' onload='this.rel=stylesheet'> with <noscript> fallback. Or move to self-hosted woff2 + @font-face in index.css.
