## Description

Quick prompt click captures `{ occasion: selectedOccasion ?? undefined, mode: selectedMode }`. The occasion list is bound to neutral-only categories (Engagement, Haldi, Mehendi, Sangeet, Cocktail, Wedding, Reception, Baraat, Vidaai, Roka, Sagai, Ganesh Puja, Bachelor Party, Bridal Shower, Destination, Festive). Not PII per se, but it is event-context that combines with `$ip` + `email` super-prop (set by identify) to reveal "User X (email known) is planning a Hindu wedding with Sangeet on Sangeet ceremony date inferred from session-end" — a profiling vector for ad-tech.

Compounds with -1201 (email in identify) + -1218 (geo). If consent is "decline", `track` returns early (analytics.ts:242 `if (!ENABLED || !ready) return`). Verify the consent banner actually gates `ENABLED`.

## Steps to reproduce

1. Open `/chat`. Select Haldi chip. Click "Help me plan".
2. PostHog Live event view → `quick_prompt_clicked { occasion: 'Haldi', mode: 'auto' }`.
3. Cross-reference with `$identify` → email is attached.
