## Steps to reproduce
1. Sign in, open a thread with existing AI messages.
2. DevTools, Network, Offline.
3. Do these three actions in sequence (don't reload between):
   - Send a new message.
   - Click the like button on the most recent AI bubble.
   - Open Reminders, click "+", fill in title/date, save.
4. Toggle "Online".

## Expected
Either all three sync to the backend within 1-2s of reconnect, OR each shows a clear "failed, retry" affordance.

## Actual
- Message: optimistic user bubble + error AI bubble. No retry, no sync.
- Like: local in-memory toggle goes through (useChat.ts:876-889) and Firestore write throws but is silently caught (useChat.ts:898 — `console.error` only). UI shows liked; backend never did. After reconnect, the local-only liked state stays liked forever, never reconciled with server.
- Reminder: `createReminder` runs a Firestore `getDocs(query(...))` to count pending reminders (reminderService.ts:174). Offline, this resolves from cache if present (Firestore IndexedDB), else throws. Toast error shown; reminder lost.

Only one of three even reports failure to the user.

## Root cause
No request queue. No `navigator.onLine` listener. Firestore offline persistence not enabled (`enableIndexedDbPersistence` never called — `grep -rn "enableIndexedDb\|enableMultiTab" src` returns 0).
