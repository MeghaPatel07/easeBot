## Description

Currency control is a native `<select>` inside a `<label>` (programmatic association OK). The `aria-live="polite"` "…" placeholder next to it announces only an ellipsis during rate loading — non-meaningful announcement to screen-reader users. Replace with "Loading exchange rate" so the live region carries real semantic value.

## Expected

`<span aria-live="polite" aria-busy={loadingRate}>{loadingRate ? "Loading exchange rate" : ""}</span>`

## Actual

`<span aria-live="polite">…</span>` — announces "horizontal ellipsis" or nothing useful.
