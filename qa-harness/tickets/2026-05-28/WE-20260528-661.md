## Description

Three planner status cards are differentiated almost entirely by hue:

- Overdue: red text + ⚠ (single character)
- To-Do: blue text + 📋
- Done: green text + ✅

Under protanopia/deuteranopia simulation (Chrome DevTools → Rendering → Emulate vision deficiencies), the red destructive shade and blue cat-budget shade flatten to similar olive/gray tones. The emoji is small enough (text-3xs) to be a barely-visible glyph at standard zoom. Net: color-blind users can't quickly tell which pile has 12 vs 3 vs 7.

Additionally the emoji is text content — SR users hear "warning [number] overdue" which is fine, but the leading `<span aria-label="Warning">⚠</span>` on line 187 is overridden by VoiceOver pronouncing the symbol literally (⚠ U+26A0). The aria-label gets ignored on a `<span>` with text content — only useful on empty elements.

## Steps to reproduce

1. DevTools → Rendering → "Emulate vision deficiencies" → Protanopia
2. Navigate to /:userId/planner with checklists in each state
3. Try to identify the three buckets without reading the labels

## Expected

Each card has a distinct shape/icon (not just color), prominently sized (≥ 20px). Text label "Overdue" / "To-Do" / "Done" visible at default zoom without color reliance. ⚠ becomes a Lucide `<AlertTriangle aria-hidden>` icon.

## Actual

Color-and-emoji-only distinction; small text-3xs labels.

## Notes

Replace emoji with Lucide icons (AlertTriangle / ClipboardList / CheckCircle), all rendered at h-4 w-4 with `aria-hidden`. Card label text bumped from text-3xs to text-xs and weighted semibold.
