## Description

When a user tabs through messages in a long chat thread, the focused message bubble may scroll into the area covered by the sticky `position: sticky top-0` header. WCAG 2.2 2.4.11 (AA, NEW) requires that when an item receives keyboard focus, it must not be entirely hidden by author-created content (sticky headers, footers, banners).

Sample obscuring elements:
- ChatHeader (sticky top)
- AnalyticsConsent banner (fixed bottom)
- CapHitBanner (fixed top)
- WeddingEaseFloater (fixed bottom-right)

Combined, focusing a message near the top or bottom of the visible area may be fully or partially covered.

## Expected

Add CSS `scroll-margin-top` (and `scroll-margin-bottom`) on focusable items equal to the sticky header / footer height. `scroll-margin-top: 4rem` ensures any focused element is scrolled clear of the header.

## Actual

Focused element can land under the sticky header — invisible focus.

## Notes

Spot-check with Tab through a long thread. Easy CSS-only fix.
