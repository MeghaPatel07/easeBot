## Steps to reproduce
1. Tab A and Tab B both showing tier=free, profile loaded.
2. User completes PayU upgrade in Tab A. Backend webhook updates Firestore profile.plan = 'pro'.
3. Tab A, within 60s, useUsageStats refetches, tier label updates.
4. Tab B, observe ProfileMenu badge, TokenPoolBar, and upgrade-CTA visibility (should hide for Pro).

## Expected
All surfaces in Tab B reflect Pro within 60s.

## Actual
- Tab B has no `onSnapshot` on the user doc and no BroadcastChannel signal.
- `useUsageStats` in Tab B might refetch on focus or interval, but it returns a different cache key (`['account','usage']`) than the profile key (`['account','me']`). Even when usage refetches, AuthContext.profile.plan is stale.
- Upgrade CTAs remain visible (annoying), TokenPoolBar might show updated quota but old tier label (inconsistent).

## Severity rationale
P0, paying customer sees old free-tier UI after paying. Direct conversion/trust impact.

fix-state-data
