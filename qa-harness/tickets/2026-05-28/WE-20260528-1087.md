## Description

Enter without Shift sends the message — standard pattern. However users with tremor, switch users, voice users may double-tap Enter unintentionally, sending a half-formed message. WCAG 3.3.4 requires reversible / confirmable / checked for legal/financial/data — chat messages aren't strictly that, but a user with cognitive impairment may have submitted PII.

## Expected

- Provide an "Undo send" affordance for ~5 seconds after each send
- OR: Settings → Accessibility → "Confirm before sending"
- The Sonner toast pattern could be: "Sent. [Undo]" — common in email apps

## Actual

Hard send, no undo.

## Notes

P3 — most users want fast send. But the toggle is a low-cost a11y accommodation.
