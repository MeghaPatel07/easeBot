## Description

`translateText` does:
```ts
body: JSON.stringify([{ text }])
```

No length check on `text`. Azure Translator's documented per-request limit is 50,000 characters. With `ENABLE_SPEECH_TRANSLATION=true`, a 10K-char message in Hindi → translates fine. A 60K-char message (only via `/chat/stream` due to -1402 bypass) → Azure returns 400 `RequestBodyTooLarge`. `withRetry` retries twice (wasting 2 round-trips), the breaker counts 3 failures, eventually trips after 3 within 60s, then refuses ALL translations system-wide for 30s (`translatorCircuitBreaker` cooldown 30s).

Net: one attacker on `/chat/stream` can trip the translator breaker → every other user with non-English input degrades to English-only for 30s.

## Expected

Cap text length at `MAX_TRANSLATOR_CHARS = 9_900` (well under Azure's 10K-per-element soft cap), chunk if longer.
