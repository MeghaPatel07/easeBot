## Description

src/pages/Index.tsx renders <ChatInput {...inputBarProps} ... /> twice: once for the expanded chat view (line 1488), once for the collapsed/initial view (line 1647). At any time only one is conditionally rendered, but the props object is computed in both code paths and (depending on isExpanded branching) the React tree may mount/unmount one on toggle.

Combined with the re-render issues (310, 316), the ChatInput's internal useEffects (textarea auto-resize at lines 90-97 of ChatInput.tsx, mode-dropdown listener at 105-119) execute on each mount, attaching/detaching mousedown+touchstart listeners on document. With every isExpanded toggle, listeners churn.

## Steps to reproduce

1. Read src/pages/Index.tsx line 1488 and 1647
2. Toggle isExpanded in React DevTools, watch event listener panel

## Expected

Single ChatInput instance whose isExpanded mode is a prop or context value.

## Actual

Two instances, conditionally rendered, causing mount/unmount churn.
