## Description

`WeddingEaseFloater` renders an `<a aria-label="Open WeddingEase in a new tab">` but `href`, `target`, and `onClick` are commented out — actual `href="#"`, no handler. The link looks functional (tooltip, ping animation, hover scale) but does nothing except jump scroll position to the top. Screen reader still announces "Open WeddingEase in a new tab, link" — lie to the user.

## Steps to reproduce

1. On desktop, open `/pricing`.
2. Tab to the bottom-right floater.
3. Press Enter.

## Expected

Either: a real link to `https://weddingease.ai` (uncomment intended code), or remove the floater entirely if it's not ready to ship.

## Actual

Page scrolls to top (`#` behavior). VO announcement is misleading. Decorative ping animation continues to draw user attention to a non-functional element.

## Notes

The component file has comments noting the previous decision to disable. Either ship live or remove from render tree.
