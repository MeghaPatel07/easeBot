## Description

When a user attaches a generated 4K image (3072×3072 PNG from the gallery) to a chat message, the bubble renders `<img className="mb-2 rounded-lg max-w-[200px] max-h-[200px] object-cover" />`. The browser downscales 3072 → 200 (or 600 at DPR 3.0). Native downscale quality varies — Safari iOS sometimes produces visibly soft thumbnails compared to e.g. Sharp/Cloudinary server-side downscale.

Better: when attaching, pre-resize via Canvas to ~600px max-dim, store the downscaled thumbnail separately, render the thumbnail in-chat, keep the original for lightbox preview.

## Steps to reproduce

1. Generate a 3K+ image in /gallery.
2. Attach it to chat (use the "Attach to chat" button from gallery).
3. Send message.
4. View the user bubble with the attached image at small size.
5. Compare with the source image opened in lightbox.

## Expected

Crisp thumbnail in chat; full-res in lightbox.

## Actual

Soft thumbnail because browser scales from 3072.

## Evidence

- ChatMessages.tsx:366.

## Notes

Bonus: bandwidth — sending a 4MB PNG to render at 200px wastes bandwidth, especially on mobile data. The Canvas pre-resize fix saves both visual quality AND data.
