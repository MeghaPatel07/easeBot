# WE-20260528-1531 — promptArchitect.ts uses response_format json_object — Azure JSON mode adds ~10-20% latency

**Severity:** P3
**Status:** triaged
**Assigned:** fix-performance
**Area:** Performance / Prompt Architect
**Discovered:** 2026-05-28

## Symptom
`promptArchitect.ts:231` requests `response_format: { type: 'json_object' }`. Azure's JSON mode enforces strict JSON output via grammar-constrained sampling, which is consistently 10-20% slower than freeform output at the same max_tokens.

Combined with `max_tokens: 800` and `temperature: 0.7`, the architect averages ~3-6s per call (-1502).

## Why this matters
- The architect output is parsed via `JSON.parse(raw)` which is robust enough to handle a markdown-fenced JSON response. Strict JSON mode is over-engineered for this use case.
- Removing JSON mode and accepting "look for the first `{...}` block" would shave ~500-800ms per call.

## Suggested fix
1. Drop `response_format` and parse first JSON block from response.
2. OR adopt `response_format: { type: 'json_schema', schema: { ... } }` (structured outputs) which is faster than freeform json_object on Azure 2024-08+ API.
3. Lower `max_tokens` from 800 to 500 — typical architect output is ~300-400 tokens of expandedPrompt + descriptors.
