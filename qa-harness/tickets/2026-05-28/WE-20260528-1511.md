# WE-20260528-1511 — Service worker missing entirely — no offline support, no asset precache, every reload is cold

**Severity:** P2
**Status:** triaged
**Assigned:** fix-frontend
**Area:** Performance / PWA
**Discovered:** 2026-05-28

## Symptom
`dist/` contains: `assets/`, `manifest.json`, `fonts.otf`, `index.html`, `worklets/pcm-recorder-processor.js`. **No `sw.js` or `service-worker.js`.**

`vite.config.ts` does NOT use `vite-plugin-pwa`. No `workbox` references in src. `manifest.json` declares standalone PWA but there is no service worker registered.

## Why this matters
- Every page reload hits the network for `index.html` + all `assets/*.js` cold (even though they're content-hashed and could be cached forever).
- No background sync for failed sendMessage calls.
- Installed PWA users get a blank screen offline (current behavior: spinner forever).

## Suggested fix
1. Add `vite-plugin-pwa` with `registerType: 'autoUpdate'`, precache `assets/*.{js,css,woff2}` (long-cached, content-hashed).
2. Network-first for `index.html`, cache-first for hashed assets.
3. Skip caching `/api/*` and `/ingest/*` — keep them network-only.
4. Add an offline fallback page.
