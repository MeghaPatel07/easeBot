## Steps to reproduce
1. Sign in. Open chat. Send a message — works.
2. Leave the tab in foreground (but no interactions) for 65 minutes.
3. Send a new message.

## Expected
Token is auto-refreshed (Firebase SDK does this), request goes through.

## Actual
- Firebase JS SDK does refresh the ID token in the background every ~55min as long as `onAuthStateChanged` or `onIdTokenChanged` is being observed AND the app is active.
- AuthContext only uses `onAuthStateChanged`, NOT `onIdTokenChanged` (AuthContext.tsx:87). It calls `getDoc` once on auth state flip and never re-reads the token.
- If the request layer (chatService) caches a stale token in a closure, the first post-expiry request 401s.
- No 401 retry-with-fresh-token logic anywhere in `services/` (grep for `getIdToken(true)` returns 0 hits in src).
