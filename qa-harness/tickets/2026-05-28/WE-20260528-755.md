## Description
IMAGE_TOOL.description doesn't filter out named designer / trademarked style invocations. A prompt like "show me a Sabyasachi-style lehenga" or "image of a Manish Malhotra bridal look" will be passed verbatim to Azure GPT-Image. Azure's own safety likely blocks branded names sometimes, but the failure mode is silent — `handleImageToolCall` just bubbles a 400 with no fallback to "I can't recreate a named designer's specific work, but I can show you a similar silhouette in [generic descriptors]". This both fails for the user AND leaves a paying customer feeling unsupported.

## Steps to reproduce
1. Stylist mode: "Generate an image of a Sabyasachi-style red lehenga."
2. LLM calls `generate_image` with the brand name in the prompt.
3. Azure rejects on trademark policy OR generates something that's pirated likeness — both bad.

## Expected
1. Pre-call: scan prompt for known designer / fashion-house names (Sabyasachi, Manish Malhotra, Tarun Tahiliani, Anita Dongre, etc.) — extract aesthetic descriptors instead ("Sabyasachi" → "regal, intricate gold embroidery on burgundy, vintage-inspired bridal lehenga with heavy zardosi work"), then call generate_image with the descriptors only.
2. Tell the user transparently: "I can't recreate a specific designer's work, but here's the aesthetic in the same family."

## Actual
No filter. Brand names pass through verbatim. Failures are unhandled.
