## Steps to reproduce
1. Sign in as Free user. AuthContext `useEffect` calls `startReplay({ isPaying: false })`.
2. User upgrades to Pro mid-session via PayU.
3. PostHog session replay continues with `isPaying: false` sample-rate logic for the rest of the session.

## Expected
Replay sampling re-evaluates when tier flips.

## Actual
The `startReplay` call lives inside `onAuthStateChanged` which only fires on auth flip, not on subsequent profile updates.

## Impact
P3 — analytics fidelity issue only; no user-visible bug.

## Fix direction
Re-call `startReplay` whenever `useUsageStats` reports tier change OR on a successful PayU webhook (best-effort).

- `src/contexts/AuthContext.tsx:124-129`
- `src/lib/analytics.ts` (not inspected in detail)
