## Description
The 4 prompts all have a "POSITIVE TONE RULE" that triggers ONLY on foul language ("Do not encourage, mirror, or amplify foul language"). There's no rule for sentiment-following — i.e. if turn 1 user is excited ("OMG SO excited for this!!!"), turn 5 user is stressed ("ugh, this is too much, I want to cry"), turn 10 user is excited again ("ok feeling better, ready to plan!"), the AI should adapt: warm-celebratory → soft-empathic-pause → warm-celebratory.

Empirically the AI keeps a baseline-warm-helpful tone throughout. Stress signals are sometimes acknowledged ("I can tell you're feeling overwhelmed") but the tone of the answer doesn't actually downshift — it still drops a 5-item checklist with the usual structure. Re-excitement is similarly not mirrored.

## Steps to reproduce
1. T1 user: "I'm SO excited!!! Just got engaged 2 weeks ago!!" → AI matches (warm).
2. T5 user: "Honestly this is so much, I'm exhausted, I don't even know where to start." → AI says "let's take it step by step" but still gives a 4-line list.
3. T10 user: "Ok feeling much better, ready to crush this!" → AI continues the same neutral helpful tone.

## Expected
- An upstream sentiment classifier (cheap heuristic or LLM-as-judge) labels each turn `excited|neutral|stressed|sad` and emits a directive prepended to system prompt: `"User signal: STRESSED — keep this reply short, soft, no lists. End with a check-in question."`
- Re-excitement detection bumps back up to celebratory mode.

## Actual
Same tone for all sentiments. The "stress" acknowledgment is a single sentence; the response shape is unchanged.

## Notes
Already partially scaffolded — assistant.ts:51 "When user is confused: 'No worries, let's take this step by step.'" — extend to a full mood map. The cleanest fix is upstream classification, not adding 15 IF clauses to the prompt.
