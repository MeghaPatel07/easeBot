## Description

`PRD-TTS-Pipeline.md` (v1.0, status "Current-State Documentation") names Gemini 2.5 Flash Preview TTS as the synthesis provider, lists the Gemini endpoint `generativelanguage.googleapis.com/v1beta/...`, the `GEMINI_API_KEY` env var, and a 6-voice preset map (Kore, Charon, Aoede, etc.). The actual runtime is **Azure Cognitive Services Speech** (`azureTTS.ts`, imported by `ttsController.ts:2`). The `geminiTTS.ts` file exists but `ttsController` does NOT import it; it is dead code from a prior pivot.

PRD also says:
- **"Middleware: requireAuth (Firebase token verification)"** — actual `requireAuth` allows guest pass-through (see WE-20260527-204 and WE-20260528-001), so TTS is open to anonymous callers.
- **"Maximum 5,000 characters sent to Gemini TTS"** — the cap is applied AFTER 8+ regex passes over the full input (see WE-20260528-003), so a malicious 19 MB request still runs through the whole regex pipeline.
- **"Pseudo-SSML tag is prepended"** — actual implementation uses real SSML `<speak><voice>` (Azure-style) and is vulnerable to injection via `voiceName` (see WE-20260528-002).

Anyone new reading the PRD-TTS-Pipeline.md will look for `GEMINI_API_KEY` env, the wrong file (`geminiTTS.ts`), the wrong endpoint, and assume the middleware actually guards the route.
