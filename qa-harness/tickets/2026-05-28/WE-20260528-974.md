## Steps to reproduce
1. Sign in as free user. Session replay initialized with `isPaying: false`.
2. Upgrade to Pro via /pricing, /checkout.
3. Profile reloads (tier change). Session replay flag is NOT re-set in the same session.

## Expected
On tier change detection (PayU webhook, Firestore profile update), re-call `startReplay({isPaying: true})` or stop the free-tier replay.

## Actual
- `startReplay` only called inside the `onAuthStateChanged` handler (AuthContext.tsx:130). Since the user is already authenticated, the handler does not re-fire on upgrade; the same replay continues.
- Analytics dashboards undercount paying-user session-replay events.
