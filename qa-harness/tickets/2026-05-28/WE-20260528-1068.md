## Description

Switch-control users navigate the entire page via a single switch — every tabbable control is scanned sequentially. In ChatMessages, each message has 4–6 interactive controls (copy, share, like/dislike, save, regenerate). With 100 messages in a thread, the switch-user scans 400+ controls to reach the composer.

There IS a skip-link at the top (WE-20260528-257 covers the missing one — Sprint 1), but within the message list itself no skip-by-N controls exist:
- No "Jump to latest message" link
- No "Skip to chat composer" link from within the list
- No grouping landmark for the message list (just a flat scroll)

## Expected

- Add `<button>Jump to latest</button>` skip-link visible/focusable when scrolled away from bottom
- Add `<nav aria-label="Skip in chat"><a href="#composer">Skip to composer</a></nav>` at the top of the message list
- Wrap each message in `<article aria-label="Message N of M">` so SR users can navigate by article landmark

## Actual

Sequential scan only, no bypass.

## Notes

This is the structural fix that benefits switch users, SR users (via landmark nav), and motor-impaired users (fewer presses). Combine with Sprint-1 -257 fix.
