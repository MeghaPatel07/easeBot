## Description

Multiple inline anchor links in body text measure 12–18px tall × 60–213px wide. Mobile: 10 of 12 interactive elements on `/privacy` fail 24px target-size; on `/terms` 7 of 9 fail. While these are inline links (the 24px rule exempts inline text targets), Apple HIG / Google Material both want 44/48px. Borderline AA; flagging for review especially because adjacent links sit very close (no padding rows).

## Notes

WCAG 2.5.8 exemption for inline text links applies, so this is technically conformant. Filing as P2 for mobile UX, not strict compliance.
