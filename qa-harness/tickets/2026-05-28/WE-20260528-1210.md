## Description

The Sprint 4 brief references `walkthrough.md` "starting prompt options" cards. The agent brief explicitly enumerates five: **Help me decide / What should I get / Help me plan / Show me ideas / Ask anything**. The FE today:

- 4 cards from `buildActionButtons` (`What should I get`, `Help me plan`, `Show me ideas`, `Ask anything`) — both mobile and desktop.
- 1 pill "Help me decide" wrapped in `<div className="glass-action-card hidden sm:flex …">` (line 1550) — desktop only.

Mobile users miss the "Help me decide" entrypoint. The spec drift is small but real: mobile users get a different empty-state CTA set than desktop users.

## Steps to reproduce

1. Load `/chat` on a phone (or DevTools <640px viewport). Count cards in empty state → 4.
2. Resize to >=640px. Count → 4 cards + 1 pill = 5.

## Expected

All 5 CTAs available at all breakpoints, or the spec gets revised to "4 cards on mobile, 5 on desktop" and the docs/PRD updated.

## Actual

Mobile is missing "Help me decide" entirely.

## Notes

Fix-frontend OR docs update. Trivial: change `hidden sm:flex` → `flex` and reflow on mobile. Or per Krish call: drop the "Help me decide" pill entirely if the 4 cards cover the spec intent.
