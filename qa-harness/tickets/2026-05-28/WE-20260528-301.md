## Description

Lighthouse mobile run (Moto G4 emulation, 4x CPU throttling, Slow 4G) measures LCP=10.3s on /chat/test123 against the production preview build. 'Needs work' threshold is 4s; >8s is effectively unusable. FCP=6.6s and TTI=10.3s confirm the page is paint-blocked for ~10 seconds on mid-tier mobile.

Root causes (see also tickets 302, 303, 304, 308):
- Single vendor chunk index-BFQDlZeM.js = 324KB gzipped, 1.2MB raw
- Route bundle Index-BI9zObHt.js = 354KB gzipped, 1.3MB raw
- NoteEditor.js (TipTap, 155KB transfer / 504KB raw) loaded eagerly on /chat (see 304)
- Render-blocking Google Fonts CSS = 1076ms wasted (see 308)
- PostHog initialized synchronously before createRoot (see 305)
- 5 long tasks reported during initial load

## Steps to reproduce

1. cd Wedding-Ease-Viva-Chat && npm run build
2. npx vite preview --port 4173
3. npx lighthouse http://localhost:4173/chat/test123 --form-factor=mobile --throttling.cpuSlowdownMultiplier=4 --only-categories=performance

## Expected

LCP ≤ 2.5s (good) or at minimum ≤ 4s (needs-work threshold)

## Actual

LCP = 10.3s, FCP = 6.6s, Speed Index = 6.6s, Performance score = 59/100
