## Description

NotificationPanel subscribes via Firestore real-time (`subscribeToNotifications`). When a new overdue/reminder/info notification arrives:

- The list re-renders with the new item visually at top
- No `aria-live` wrapper, no `role="log"` — SR users get nothing
- The unread count badge in the sidebar/header (NotificationButton, not in this file) also updates silently

Unlike the chat log (where the user just sent a prompt and is expecting a reply), notifications can arrive at any time — passive arrival is precisely the case live regions exist for.

## Steps to reproduce

1. SR on, open Notifications view
2. From another browser, trigger a reminder (or wait for the generateOverdueNotifications cron)
3. Observe — silent update

## Expected

Wrap the notification list in `<section role="log" aria-live="polite" aria-relevant="additions" aria-label="Notifications">`. Sidebar badge gets `aria-label="{n} unread notifications"` and updates when count changes.

## Actual

No live region; silent updates.

Same issue for the unread-count badge on the NotificationButton trigger (file not yet located — likely in ProfileMenu.tsx or sidebar).
