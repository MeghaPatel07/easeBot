## Description

OTP single-digit input cells use `maxLength={1}`. Verified via grep. The inputs likely don't all set `inputMode="numeric"` + `autoComplete="one-time-code"` consistently. Without `inputMode="numeric"`, Android Chrome opens the full QWERTY keyboard for the OTP cells, slowing entry. Without `autoComplete="one-time-code"`, iOS doesn't surface the SMS-OTP suggestion banner.

Best practice for OTP inputs (per WHATWG / web.dev):
- `inputMode="numeric"` (numeric keypad).
- `autoComplete="one-time-code"` (iOS SMS auto-fill).
- `pattern="[0-9]*"` (legacy fallback).
- `maxLength={1}` per cell or `={6}` on the single big input alternative.

## Steps to reproduce

1. Sign in via phone-OTP on an Android device.
2. Tap an OTP cell.
3. Observe full QWERTY keyboard.
4. Tap an OTP cell on iOS Safari with an SMS code in Messages.
5. Observe whether the "From Messages" suggestion appears.

## Expected

All three configured per spec above.

## Actual

Inconsistent; some inputs missing `inputMode` and/or `autoComplete`.
