## Steps to reproduce
1. Create a reminder: "Pay venue deposit", date+time = 10 minutes from now, leadTime = 5 min.
2. Close the tab (or backgrounded for too long without an SW).
3. Wait for trigger time.

## Expected
Browser push notification fires regardless of tab state.

## Actual
- No service worker exists (see 954). All reminder delivery is via in-app `NotificationPanel` polling the Firestore listener.
- If tab is closed, nothing fires.
- If tab is in another desktop space / OS background, browser may suppress in-app sound; no native OS notification fallback.
- `Notification.requestPermission()` is never called anywhere (grep confirms).
