1. Send a complex prompt that triggers a long LLM response (e.g. "write a 4000-word ceremony script").
2. Watch the stream over ~30-60s.
3. If a corporate proxy / CDN is in the path (Cloudflare default 100s, AWS ALB 60s), the connection may be dropped.
