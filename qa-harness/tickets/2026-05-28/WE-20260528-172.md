## Description

```ts
const providers = useMemo(() => {
  const fromProfile = profile?.linkedProviders
  if (fromProfile && fromProfile.length > 0) return fromProfile
  return readFirebaseProviders()
}, [profile?.linkedProviders, profile?.uid])
```

The deps include `profile?.linkedProviders` — the array reference. If the backend updates linkedProviders (e.g. user linked Google in another flow), the AuthContext doesn't refresh (WE-20260528-152) so the array reference never changes here, and the memo doesn't recompute. The Connected Providers list stays at the pre-link state.

## Steps to reproduce

1. Sign in with email/password. Open AccountTab; note Connected providers panel shows Password only.
2. In a SEPARATE Firebase Auth flow (server-side admin link, or another tab) link Google to this account.
3. Without reloading Tab A, refresh AccountTab view — providers panel still says Password only.

## Expected

Panel reflects the freshly-linked Google account.

## Actual

Panel says only Password (until reload).
