## Description

easebot.png is only 275×300 pixels (verified via 'file' command) but its file size is 226KB. A 275×300 PNG of a mascot should be ≤ 30KB. This suggests the file is either uncompressed or contains transparency/depth that could be reduced.

Bundled as easebot-D6BiD7YY.png in dist/assets via Vite asset import (in ChatMessages.tsx line 26: import easebotAvatar from '@/assets/images/easebot.png';).

## Steps to reproduce

1. file Wedding-Ease-Viva-Chat/dist/images/easebot.png
2. ls -lh dist/images/easebot.png

## Expected

Compressed PNG ≤ 30KB or WebP/AVIF ≤ 15KB at displayed dimensions.

## Actual

226KB for a 275×300 image.
