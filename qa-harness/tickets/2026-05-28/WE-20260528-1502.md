# WE-20260528-1502 — Image-gen flame: Prompt Architect adds ~3-6s LLM hop before the image API is even called

**Severity:** P1
**Status:** triaged
**Assigned:** fix-performance
**Area:** Performance / Image generation
**Discovered:** 2026-05-28

## Symptom
Sprint 1 -108 reported 47s total image-gen latency. Sprint 3 -1103 attributed 8s to Sharp. **The other ~39s breaks down as:**

| Stage | Where | Estimated time | Evidence |
|---|---|---|---|
| (a) Prompt enhancement | `expandWithPromptArchitect()` — separate gpt-4o JSON call, max_tokens=800 | **3-6s** | promptArchitect.ts:223-232 |
| (b) Azure GPT-Image-1.5 call | `callAzureImageGeneration` (quality='high', 1024x1024) | **20-30s** | imageGeneration.ts:303-318 |
| (c) Response parse + base64 | `res.json()` then `Promise.all(rawImages.map(compressImage))` — Sharp runs even when input ≤2MB (early return) | **0.1-1s** | imageGeneration.ts:340-343 |
| (d) Sharp post-process | `postProcessImage` upscale (lanczos3 2x) + format convert | **6-10s** (Sprint 3 -1103) | imagePostProcessor.ts:32-47 |
| (e) Firestore + Storage write | `storeMultipleImages` → `uploadBytes` then `setDoc` | **1-3s** | imageStorage.ts:108-160 |

**Slowest hop: (b) Azure image API.** Architect (a) is a hidden cost that adds zero user-visible benefit when the user's prompt is already detailed.

## Why this matters
- The 3-6s Prompt Architect call runs **serially BEFORE** Azure image — pure dead time on the user clock.
- The architect uses `temperature: 0.7` + `max_tokens: 800` + `response_format: 'json_object'` — JSON mode costs ~30% more on Azure.
- For short prompts ("a red lehenga"), architect helps. For long detailed user prompts, it adds latency without quality gain.

## Suggested fix
1. **Skip the architect** for prompts longer than ~120 chars or already containing photographic keywords (lighting/lens/composition).
2. Add `ENABLE_PROMPT_ARCHITECT=false` per-mode override.
3. Run architect **in parallel** with a speculative image call kicked off with the raw prompt — if architect finishes first AND meaningfully differs, abort the speculative call.
