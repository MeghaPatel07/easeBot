## Description

The chat composer is a plain `<textarea>` with no `autocomplete` directive. Browser password managers may try to autofill it if the user is, say, on a shared computer and the password manager mistakes the box for a credentials field. More importantly, when a user pastes accidentally-copied sensitive content (password, credit-card number, OTP), the SR reads it character-by-character.

## Expected

Set `autocomplete="off"` (or `autocomplete="message"`, which exists in the BCP-47-adjacent autofill vocabulary) on the chat textarea to prevent PM injection.

For the SR-readback risk, this is harder — could add a "private mode" toggle that mutes SR feedback temporarily, but lower priority.

## Actual

No autocomplete attribute = browser default behavior, occasionally surfacing PM popups in chat.

## Notes

Lower than -1051 because the chat textarea isn't an *auth* field — but it's a regular leak vector and trivial fix.
