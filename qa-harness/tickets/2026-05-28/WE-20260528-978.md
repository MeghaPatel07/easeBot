## Steps to reproduce
1. Start a long generation.
2. Click Stop after ~3s.
3. Check token meter (useUsageStats).

## Expected
Either tokens consumed are refunded for the abort, OR a clear "N tokens used (partial)" hint.

## Actual
- `stopGeneration` calls AbortController.abort() and fires `/api/chat/cancel` (useChat.ts:939-943).
- Backend may have already committed token count before receiving the cancel (no refund logic visible).
- Usage meter polls every 60s, will show the full pre-cancel token count.
- User effectively pays for tokens they did not get a full reply for.
