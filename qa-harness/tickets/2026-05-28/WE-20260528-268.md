## Description

Mobile audit: AnalyticsConsent Decline 66×28 and Accept 65×28 are below WCAG 2.2 AA 24px-min-height target (height is 28px which scrapes by) but well below 44×44 platform minimum. Combined with `WE-20260528-254` (banner overlaps chat input), mobile users face two small adjacent buttons in a narrow zone.

## Expected

Min height 44px (or 48px Material). Buttons should occupy a full-width row each, or stack vertically on narrow viewports.

## Actual

Two 28px-tall buttons squeezed at right of banner.
