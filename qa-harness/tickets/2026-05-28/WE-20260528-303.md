## Description

Index.tsx is a 1668-line god-component that handles every primary route (/, /chat, /gallery, /planner, /notes, /budget, /timeline, /shopping, etc — see App.tsx lines 71-87). The compiled bundle is 1,316.92 KB raw / 354.70 KB gzipped. Lighthouse reports 250KB (72%) of this is unused on /chat alone.

Because every primary route renders the same Index component, all view modules (NotesView, BudgetDashboard, TimelineView, ShoppingListView, PlannerView, GalleryView, NotificationPanel, etc.) are statically imported at the top of Index.tsx and ship in this chunk regardless of which route the user actually lands on.

## Steps to reproduce

1. cd Wedding-Ease-Viva-Chat && npm run build
2. Inspect dist/assets/Index-BI9zObHt.js
3. View Lighthouse unused-javascript audit for /chat

## Expected

Each route's view loads its own ~50KB chunk, not 354KB up-front.

## Actual

Index.tsx imports 14+ heavy view components eagerly. The chunk has 72% unused code per Lighthouse.

## Notes

Recommend: split Index.tsx into per-view lazy chunks. Convert all sidebarView branches (lines 1240-1366) to React.lazy + Suspense. Each view (NotesView, BudgetDashboard, etc.) should be its own dynamic import.
