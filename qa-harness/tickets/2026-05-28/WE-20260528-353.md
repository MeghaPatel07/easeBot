## Description
The `userPersonalization` field accepts a tone/verbosity/emoji slider set, and `buildPersonalizationSuffix()` injects them into the system prompt. When `verbosity=0` (most concise) and `toneFormality=100` (most formal), the assistant should produce a tight, structured, short reply. Empirically the response is the same ~6-paragraph numbered list it produces with default settings — the slider has no observable effect on output length or structure.

## Steps to reproduce
```bash
curl -s -X POST http://localhost:3001/api/chat/stream \
  -H "Content-Type: application/json" \
  -d '{
    "message":"Tell me about wedding planning",
    "userPersonalization":{"toneFormality":100,"verbosity":0,"emojiUse":0}
  }'
```

## Expected
With `verbosity=0`, output is ≤4 short lines per the prompt's own "Keep responses 2-4 lines" rule. With `emojiUse=0` no emoji are emitted (this part is OK in the test).

## Actual
6-section response: full intro paragraph, 5 numbered sub-headings with 2-sentence elaborations each (~200 words). The "verbosity=0" signal had no visible effect — output is indistinguishable from a no-personalization call.

```
"Wedding planning can feel like a big task, but breaking it into smaller steps makes it manageable and even enjoyable! Here's a quick overview of how it typically flows:
1. **Set Your Budget & Guest List** …
2. **Book the Big Vendors Early** …
3. **Choose Your Style & Theme** …
[…]"
```

## Notes
Look at `buildPersonalizationSuffix` in `utils/toneInjector.ts`. Either (a) the suffix text is too soft ("respond concisely" instead of a hard ceiling like "≤40 words, no markdown headings, one paragraph"), (b) the suffix is dropped when other suffixes are appended (vibe + force-image + guest-limitation + last-image — see chatController.ts:709-715 chain), or (c) it's overridden by the assistant prompt's own "RESPONSE STRUCTURE" template which says "ACKNOWLEDGE / GUIDE / LEADING QUESTION" regardless of verbosity. Recommend a hard token-budget cap injected at the messages level when verbosity ≤ 25.
