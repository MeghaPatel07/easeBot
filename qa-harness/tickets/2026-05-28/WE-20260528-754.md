## Description
`buildImageGenPrompt(userPrompt, styleContext)` unconditionally appends `". Modern editorial photography style, soft golden-hour lighting, shallow depth of field, film-inspired color grading with lifted blacks and warm highlights, clean composition with negative space, aspirational and Pinterest-worthy aesthetic."` to EVERY user image prompt.

If the user asks: "an image of my late grandmother who passed away last year, present at the wedding" the resulting prompt becomes a memorial/grief request stapled to "aspirational and Pinterest-worthy aesthetic." The model will either produce something tonally jarring or be blocked by Azure safety mid-pipeline with no graceful handling. There's NO sensitivity classifier upstream that says "if the prompt contains death/memorial/loss vocabulary, switch to a softer style suffix and have the assistant reply with empathy first."

## Steps to reproduce
1. Send (stylist or assistant mode): "Can you visualize my dead grandmother at my wedding?"
2. LLM calls `generate_image` (trigger keyword "visualize" matches).
3. `buildImageGenPrompt` appends the editorial-Pinterest suffix.
4. Either Azure 400s on a safety-violation OR returns a tonally wrong image OR the text response from the LLM is breezy.

## Expected
- An upstream sensitivity detector flags grief/loss/death keywords (`died`, `late`, `passed away`, `memorial`, `loss`, `funeral`) BEFORE calling `generate_image`.
- If flagged: refuse to generate, reply with empathy and an alternative ("I can't generate a portrait like that, but if you'd like, we can plan a meaningful tribute moment in the ceremony — a memorial table, a moment of silence, an honorarium").
- If still proceeding: swap the trailing styling suffix for a sensitive one ("respectful, soft natural light, dignified composition") and never `aspirational and Pinterest-worthy`.

## Actual
Code path is unconditional. No empathy gate. No prompt branching.

## Notes
Same applies to other trauma cases: "image of my ex at my wedding", "image of a runaway bride scene", "image of my partner who left me." Add a grief/sensitivity rail at the `handleImageToolCall` entry (chatController.ts:434+).
