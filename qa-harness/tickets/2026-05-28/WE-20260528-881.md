## Description

BudgetDashboard imports `ChevronDown, ChevronRight` (line 2) and uses them as **separate** icons for collapsed/expanded states (per the import comment + line ~203). This means:
- Collapsed: `<ChevronRight>`.
- Expanded: `<ChevronDown>` (swap, not rotate).

The visual transition is instantaneous (DOM swap) — no smooth rotation animation. Compare to the chat-input mode dropdown which uses `<ChevronDown className="rotate-180">` for the open state — smooth `transition-transform`.

Inconsistency: same app, two patterns for the same UX idiom. Easier to standardize on rotate.

## Steps to reproduce

1. Open /budget.
2. Click a category row to expand.
3. Observe instant chevron swap (no rotation).
4. Compare with ChatInput mode dropdown.

## Expected

Single `<ChevronRight className={cn('transition-transform', expanded && 'rotate-90')} />`.

## Actual

Swap, no animation.

- BudgetDashboard.tsx:2 imports.
- BudgetDashboard.tsx:203 conditional render.
