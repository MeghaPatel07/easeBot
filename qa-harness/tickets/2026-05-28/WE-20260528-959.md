## Steps to reproduce
1. Open DevTools console, fill localStorage to ~9MB:
   ```js
   try { localStorage.setItem('junk', 'x'.repeat(9_000_000)) } catch(e) { console.log(e) }
   ```
2. Try to toggle theme (writes `easebot-theme`).
3. Try to edit a note (writes `easebot:note-draft:<id>`).
4. Send a guest message (writes `easebot-guest-msg-count`).

## Expected
Either keys are written successfully (small payload), or graceful fallback with user warning.

## Actual
- Theme write is wrapped in try/catch (ThemeContext.tsx:46-49) — silently swallows.
- Note draft write is wrapped (useNoteEditor.ts:43 comment confirms) — silently swallows. Note draft is LOST without warning.
- Guest count writes (Index.tsx:394, 845) are try/catch silent. **Guest quota tracking BREAKS — user could send unlimited messages.**
- `phoneCredentialStore.ts:38` — `setItem` NOT wrapped in try/catch — throws and crashes signup flow.
