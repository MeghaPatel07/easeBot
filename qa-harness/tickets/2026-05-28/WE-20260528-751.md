## Description
Stylist scope is "Help couples define their wedding aesthetic, suggest color palettes, recommend dress silhouettes." A planner-shaped question ("when should I send save-the-dates", "what's the booking order for vendors") arrives in a stylist-pinned session — the stylist prompt has no clause that says "if the question is about timing/scheduling/booking, hand off". Static read of the prompt shows zero ROUTING RULES section (planner.ts has one — stylist.ts does not). The model will answer planner questions stylistically (probably with palette analogies), violating its scope.

## Steps to reproduce
1. Pin stylist mode (UI mode toggle or `"mode":"stylist"` in payload).
2. Send "when should I send out wedding invitations?"
3. Stylist will answer in-mode rather than route to planner.

## Expected
Either (a) prompt includes a ROUTING RULES block: "If user asks about timing, booking, vendor order, deadlines — say 'that's more a planning question, let me hand you off' and the controller should re-route"; or (b) modeRouter should re-classify mid-conversation when the message pattern dominantly matches another mode.

## Actual
No routing back-channel exists. Stylist replies with palette/silhouette framing to scheduling questions.
