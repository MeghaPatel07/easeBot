## Description

The "Hi! I'm here to help..." string has no explicit `lang` or emoji-strip, and decorative emojis in other UI surfaces (vibe presets often imply emoji rendering, mode pills, hero copy) are read by SR with their full Unicode name — sometimes useful, sometimes noise ("Hi exclamation mark, U plus 2003 horizontal three-em space, U plus 2003, I apostrophe m...").

Specifically `Hi!   ` (with multiple non-breaking spaces) — SR reads each space character. Same in tag presets if any include emoji.

## Expected

- Use single normal space; SR reads it once
- For decorative emojis, wrap in `<span aria-hidden="true">` and provide alt text via adjacent `<span class="sr-only">`
- Audit all hero/empty-state copy for non-standard whitespace

## Actual

`Hi!&nbsp;&nbsp;&nbsp;<span>...</span>` — three spaces, read as three pauses.

Minor but accumulates across the app.
