## Description

Live probe on 2026-05-28 17:29Z:

```
curl -X POST http://localhost:3001/api/tts \
  -H 'Content-Type: application/json' \
  -d '{"text":"Same exact reply text for cache test on this sprint 4 audit","language":"en"}'
→ HTTP 200, 226244 bytes wav
```

No `Authorization` header, no rate-limit visible, no quota deduction. This burns Azure TTS quota per request from anyone on the public internet (once the backend is exposed beyond localhost). Confirms S1 -001 (anonymous Azure quota theft) STILL OPEN on main on 2026-05-28.

Also confirms `voiceName` is still accepted from req.body (line 27) and passed to `generateSpeech` without an allowlist — S1 -002 SSML-injection vector STILL OPEN.

## Steps to reproduce

```bash
curl -X POST http://localhost:3001/api/tts -H 'Content-Type: application/json' \
  -d '{"text":"hi","voiceName":"any-azure-voice-id"}' -o /tmp/x.wav
```

`requireAuth` middleware mounted on `/api/tts` route. `voiceName` allowlist (en-US-AriaNeural, hi-IN-SwaraNeural, etc.). Per-uid rate limit.
