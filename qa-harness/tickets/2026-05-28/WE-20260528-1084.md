## Description

Per-message action icons (copy, share, like/dislike, regenerate, save) at lines 390-408 are styled `h-4 w-4` (16px) — clearly below the 24×24 minimum. WCAG 2.5.8 exempts inline / equivalent-text-alternative buttons, but here:
- The button bounding box (with padding) may exceed 24px — needs measurement
- The icon itself is 16px which is sub-threshold for users with motor impairments
- Adjacent buttons in the row touch — fails the "sufficient space around" exception clause

## Expected

`h-10 w-10` (40px) on mobile, `h-8 w-8` minimum on desktop. Maintain visual subtlety via lower opacity at rest.

## Actual

Crowded 16px icons.
