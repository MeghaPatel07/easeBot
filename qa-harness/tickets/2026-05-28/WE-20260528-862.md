## Description

When a backend endpoint returns 500 (or network drops) during an active user action, the surfaced error toast is consistently the string **"Something went wrong. Please try again."** — across:
- Chat send (`useChat.ts:829`).
- Auth forgot-password (`authService.ts:77`).
- Account profile save (toast in AccountTab).
- Budget category add (no error toast at all — error just logged to console).
- Planner checklist save (same pattern, console-only).
- Notes save (console-only).

Issues:
- **No retry button** in the toast. User has to manually re-trigger the action. For chat send, that means re-typing.
- **No correlation/request ID** surfaced for support escalation.
- **No distinction** between 500 (server) vs 503 (overloaded — retry-after) vs network-failure (retryable). All same string.
- For silent-fail flows (Budget, Notes, Planner — error only in console), the user's edit appears to save (optimistic UI) but is actually lost on next reload.

## Steps to reproduce

1. Backend dev down OR DevTools → Network → "Offline" mid-flow.
2. Try: send a chat message; save a profile; add a budget category; save a note.
3. Observe: chat shows generic "Something went wrong"; budget/note silently swallow the error.

## Expected

Standardize an `errorToHumanString(error: Error): {title, body, actionLabel, actionFn}` helper:
- 500 → "Server hiccup. Tap to retry." + retry button that re-runs the original mutation.
- 503 → "We're temporarily overloaded. Retrying in 5s…" (auto-retry).
- Network failure → "You appear to be offline. Will retry when connection returns." (queue).
- Validation 400 → echo field-level error from backend.
- 401 → "Session expired. Sign in again." + link to /login.

Every silent-fail callsite (Budget, Notes, Planner mutations) MUST surface a toast.

## Actual

Generic copy or silent failure.

## Evidence

- useChat.ts:829 — `let errorText = 'Something went wrong. Please try again.'`
- authService.ts:79 — same string.
- BudgetDashboard.tsx and PlannerView.tsx — no `toast()` call on mutation errors.
