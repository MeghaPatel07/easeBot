## Steps to reproduce
Static grep:
- `useMutation` is used ONLY in `src/hooks/useAccount.ts` (2 mutations: profile, preferences).
- `useQuery` is used ONLY in `useAccount.ts` and `useUsageStats.ts` (2 hooks).
- Every other data domain (checklists, reminders, notes, saved items, shopping, budget, projects, timeline events, notifications, chats, messages, comments, payments) uses raw Firestore `onSnapshot` + local component state.

## Expected
A consistent data layer. Mutations should either:
- All use TanStack Query (with `onSuccess: invalidateQueries`), OR
- All rely on Firestore real-time listeners (so writes propagate via snapshot regardless of which client wrote).

## Actual
Mixed: most domains use snapshots (good — they DO propagate cross-tab via Firestore), but a few critical reads bypass them:
- `getDoc` for user profile (Sprint 1 -152)
- `getAccountMe` REST fetch in `useAccount` — competes with the same user doc that other components might read directly.

The Sprint 2 brief asked for "TanStack Query invalidation matrix — pick 10 mutations". Reality: only 2 mutations exist (profile, preferences). The other 8 in the brief (createChecklist, etc.) are bare async service calls. They DO trigger Firestore writes that DO trigger snapshots on OTHER subscribers — so the matrix passes for those, by virtue of Firestore snapshots, not React Query.

## Impact
P1 — architecture debt. Symptoms: WE-20260527-152, -161, -162, -175 root-cause stem from this.

## Fix direction
- Pick one model. If sticking with `onSnapshot`-driven UI, kill `useAccount`'s REST `useQuery` and replace with `useDocSnapshot(['users', uid])`. Then mutations don't need explicit invalidation — Firestore handles it.
- If standardizing on React Query, wrap every `subscribeToX` in `useQuery({ queryKey: [domain, id] })` and call `qc.setQueryData` from the snapshot callback. Then `useMutation`s with optimistic updates become idiomatic.

## Evidence
- Grep: `useMutation` 2 hits, `useQuery` 2 hits, `useQueryClient` 4 hits across entire src/.
- Compare: `onSnapshot` 22 hits.
