## Description

`TabsTrigger` buttons have only `data-[state=active]:bg-primary/20 data-[state=active]:text-primary` for active state — no `focus-visible:` styling. With keyboard navigation between tabs using arrow keys (Radix default), the user sees only the active-state change, not a distinct focus-vs-active visual. If a tab is focused but not active (after arrow + before Enter), there is no indicator.

## Expected

`focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2` on each TabsTrigger.

## Actual

Focus is invisible when distinct from active.
