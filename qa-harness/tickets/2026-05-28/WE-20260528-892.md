## Description

AttachmentPicker (line 376) renders `<EmptyState msg={notes.length === 0 ? 'No notes yet. Create one in Notes.' : 'No notes match.'} />` for notes, with similar copy for checklists/timeline/images.

The copy "Create one in Notes" is **text only**. There's no button/link to actually open Notes. User has to:
1. Close the attachment picker.
2. Close the chat (or use sidebar).
3. Navigate to /notes.
4. Create a note.
5. Return to /chat.
6. Re-open attachment picker.

That's a 6-step interruption. Should be a 1-step CTA inside the picker.

## Steps to reproduce

1. Sign up fresh.
2. Open /chat.
3. Click attachment icon.
4. Browse to Notes tab — see empty state with no link.

## Expected

`<EmptyState msg="..." actionLabel="Open Notes" onAction={() => navigate('/notes')} />` — closes picker, navigates.

Or: inline "Create note" button that opens a quick-create dialog without leaving chat.

## Actual

Dead-end copy.
