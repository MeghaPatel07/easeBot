## Steps to reproduce
1. Open app. Send a message (usage updates).
2. Switch to another tab. Wait until next refetch tick is imminent (~58s).
3. Switch back.

## Expected
Single coalesced refetch.

## Actual
- TanStack Query DOES coalesce in-flight requests via the deduper. But if a previous request had just resolved (200ms before focus), focus triggers a refetch AND the 60s interval triggers another within the staleTime window — both treated as new because staleTime expired.
- Minor perf hit; no functional bug.

## Suggested owner
fix-perf
