## Code analysis
`SignUpModal.tsx:181-188` calls `onSnapshot(doc(db, 'users', signupUser.uid))` and returns the unsubscribe from `useEffect`. That's correct lifecycle handling. HOWEVER if `signupUser` changes mid-modal (rare: user goes back, restarts signup with different email/method), the cleanup function fires but the new effect re-subscribes to the new uid — net OK.
