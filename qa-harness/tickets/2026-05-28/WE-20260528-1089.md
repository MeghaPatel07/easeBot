## Description

The Reset chip uses `<span className="sr-only sm:not-sr-only text-[11px] sm:text-xs font-medium">Reset</span>` — clever pattern: SR users always hear "Reset", sighted users only see it ≥ sm. Combined with `aria-label="Reset occasion and mode"`, it's good practice.

HOWEVER nearby chips (occasion list 1627-1638) just render `{occ}` text — at mobile they fit, but if the layout overflows or the chip text gets truncated visually via CSS, SR + visible text diverge. Consistency: standardize the sr-only/visible pattern across all chips.

## Expected

Audit all chip-row buttons in Index.tsx — apply consistent aria-label + sr-only/responsive-text pattern.

## Actual

Reset chip is the standout good example; others should follow.
