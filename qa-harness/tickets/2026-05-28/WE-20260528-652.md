## Description

When the user asks Viva to generate an image, the UI shows three sequential visual cues — none of which are exposed to assistive tech:

1. **Typing indicator → "generating..." / "creating your image"** (lines 968-970) — wrapped in `<p>` only, no `role="status"` or `aria-live`.
2. **Per-message inline skeleton → "generating image..." / "this may take a few seconds"** (lines 602-603) — same: visual-only.
3. **Partial preview → "refining image..."** (line 590) — visual-only.

Image generation can take 8-25 seconds. SR users who fire off "make me a save-the-date design" hear nothing for 25 seconds and assume the app froze. They cannot tell when generation completes either — see -654.

## Steps to reproduce

1. Enable VoiceOver
2. Switch mode to Image
3. Send "make me a Goa beach wedding invite"
4. Listen for any status — there is none

## Expected

Polite live-region announces "Generating image…" once at start; "Image generation complete" (with brief alt text) when finished; "Image generation failed: {reason}" on error.

## Actual

Silence for the full duration. User has no signal that the model is working or finished.

## Notes

Wrap each status string in `<p role="status" aria-live="polite">…</p>` (Sonner / native live region). Suppress the multi-stage chatter by announcing only state transitions, not the shimmer text itself.
