## Description

Opening the share dialog for a note that has no existing shares shows the dialog with an empty list section — no copy explaining "This note hasn't been shared yet. Use the form above to create a share link." The form is at the top; the list area below is just blank space.

Better empty state with one-line copy + arrow pointing to the form fixes the confusion.

## Steps to reproduce

1. Open /notes, pick a note never shared.
2. Click share icon.
3. Observe: form at top + blank list area below.

## Expected

```
[icon] No shares yet
Use the form above to create your first share link.
```

## Actual

Blank list area.
