## Description

Empty-state copy: "You'll see reminders for upcoming deadlines here". But notifications come from:
1. Checklist due-dates → user must have checklists.
2. Timeline events → user must have events.
3. Shared-with-me notes → user must have collaborators.
4. Payment / billing reminders → user must be on a paid tier.

A free-tier user with no checklists / no timeline / no collaborators has NO PATH to ever see anything here. The copy promises something that won't happen for them.

Better empty-state branches:
- If user has no checklist → "Create a checklist to get reminders". CTA → /planner.
- If user has checklists but none have due-dates → "Add due dates to your checklist items to see reminders here". CTA → /planner.
- If user has paid tier but no collaborators → "Invite a partner to share notifications". CTA → invite modal.

## Steps to reproduce

1. Fresh signup.
2. Open /notifications.
3. Observe misleading copy.
