## Steps to reproduce
1. Set theme to dark. Reload (hard reload, Cmd+Shift+R).
2. Observe page in first 200ms.

## Expected
No light flash. Background is already dark before any content paints.

## Actual
- On Chrome (desktop) the boot script runs fast enough — no visible flash.
- On Safari (iOS), the inline `<script>` in `index.html` that reads `localStorage` and sets `<html>.classList` runs but the browser sometimes paints a white background between HTML parse and CSS apply.
- Reported as flicker on Sprint 4 (Hana) per ThemeContext.tsx:11-13 comments — but the fix only addresses post-mount, not pre-paint.
