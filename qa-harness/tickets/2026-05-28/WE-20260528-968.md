## Steps to reproduce
1. First-time visit. Open `/` in Tab A and Tab B. Banner visible in both.
2. In Tab A click "Accept all".
3. Observe Tab B without reload.

## Expected
Banner in Tab B disappears within 1s.

## Actual
- localStorage write in Tab A; Tab B's banner uses `useState` initialized from localStorage at mount. No `storage` event listener — banner persists.
- User re-clicks Accept in Tab B. Two separate `consent_accepted` events to PostHog — analytics record shows the same user "accepted" twice in 5 seconds. GDPR audit confusion.

## Severity rationale
P0 because: (a) duplicate consent records, (b) user friction, (c) consent-record inconsistency raises legal compliance questions.
