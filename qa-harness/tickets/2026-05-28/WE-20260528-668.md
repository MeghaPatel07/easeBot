## Description

The gallery shows images in a 3-column (mobile) / 8-column (desktop) `<button>` grid. Arrow keys ONLY work *inside the lightbox* (after a thumbnail is opened). At the grid level:

- Tab moves linearly through thumbnails in DOM order — for 50 images, that's 50 Tab presses to reach the bottom row
- Arrow keys do nothing — user expects ↑ ↓ ← → to navigate a 2D grid
- No `role="grid"` / `role="gridcell"` semantics — assistive tech announces just "button, button, button…"

The lightbox keyboard support (Escape/Arrows/+/-) is good — credit to that. The grid itself is the problem.

## Steps to reproduce

1. Keyboard only
2. Navigate to /:userId/gallery with ≥ 30 images
3. Tab to the grid
4. Try Up/Down/Left/Right arrows

## Expected

Grid wrapped in `role="grid" aria-rowcount aria-colcount`; each thumb is a `role="gridcell"`. Arrow keys move focus across the 2D layout. Tab enters / exits the grid as a whole.

## Actual

Linear Tab; no arrow-key support.

## Notes

This compounds with -657 (silent loading). The whole gallery surface is keyboard-hostile. Combine with `useRovingTabIndex` from `react-aria` or a hand-rolled grid handler.
