## Description

The three notification types render distinct icons (AlertTriangle / Bell / Info) — good, that's shape distinction. But each is colored by `text-destructive` / `text-warning` / `text-primary` with no text label and the icons themselves don't have `aria-label` or surrounding `<span class="sr-only">`. Under tritanopia / achromatopsia simulation, the three icons appear similar in luminance. SR users hear nothing about the type at all.

## Steps to reproduce

1. Achromatopsia simulation
2. View notifications list — types appear similar gray
3. SR on → no type announcement, only the body text

## Expected

Each TypeIcon emits `aria-label` ("Overdue", "Reminder", "Info"). Visually, also surface the type as a tiny `<span>` label beside the icon — not color-only.

## Actual

Color-only differentiation; SR hears nothing about the type.

## Notes

Two-line fix: add `aria-label` to each switch branch in TypeIcon, plus a sibling visible `<span>` for sighted users in cognitive-a11y mode (or as a tooltip).
