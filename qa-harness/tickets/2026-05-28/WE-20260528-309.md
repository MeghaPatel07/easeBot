## Description

Line 53 of index.html declares <link rel='preload' href='/images/IMG_3917.PNG' as='image' type='image/png' />, but no such file exists in public/images/ or dist/images/ (only easebot.png, logo.png, typo.png).

This causes a wasted preload directive. Lighthouse network waterfall shows the request transferring 5KB which is likely the SPA index.html itself returned for unknown paths (Vite preview falls back to index.html for missing assets), wasting both bandwidth and the browser's preload-prioritization budget.

## Steps to reproduce

1. cat Wedding-Ease-Viva-Chat/index.html | grep preload
2. ls Wedding-Ease-Viva-Chat/public/images/

## Expected

Either: remove the preload line; or: add the actual IMG_3917.PNG to public/images/.

## Actual

Preload directive references a non-existent file. SPA fallback returns index.html (5KB) for the preload request, polluting the preload queue.

## Notes

Quick fix: delete line 53 of index.html.
