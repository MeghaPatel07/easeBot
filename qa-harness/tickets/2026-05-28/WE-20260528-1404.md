## Description

`processInbound` flow for typed mixed-script text like `"Can you help me plan haldi नमस्ते?"`:
1. `detectLanguage(rawText)` returns `'en'` (Azure detects majority language → English).
2. `hasNonLatinScript` regex matches U+0900-U+0DFF → `true`.
3. `shouldTranslate` is `true` because of script flag.
4. `translateText(rawText, 'en')` sends WHOLE text to Azure, which returns the English version (Hindi portion translated; English passthrough).
5. Because `hasNonLatinScript && detectedLanguage === 'en'`, the code reassigns `detectedLanguage = detectLanguageFromScript(rawText)` → returns `'hi'` (first matching script range).
6. Downstream `determineTargetLanguage(undefined, 'hi') → 'hi'`. The system prompt receives the Hindi language instruction.
7. The user gets a Hindi-only response despite typing 95% English.

This is broken for code-switching ("Hinglish") users — Indians who mix scripts heavily, which is the product's primary audience.

A complementary bug: `detectLanguageFromScript` priority order has Gujarati first. A user typing `"Hello, मेरी शादी है"` (Hindi Devanagari) plus accidentally one Gujarati char (e.g. from a copy-paste) routes to Gujarati response. The ordering is comment-justified but unsound — pick the script with the MOST characters, not first-match.

## Steps to reproduce

```bash
ENABLE_SPEECH_TRANSLATION=true
# (Requires speech-translation flag ON. With it OFF, this code path is dormant — see line 17-19 of inbound.ts.)
# Send: "Can you help me plan haldi नमस्ते?"
curl -s -X POST http://localhost:3001/api/chat -d '{"message":"Can you help me plan haldi नमस्ते?"}' -H "Content-Type: application/json" | jq '.responseLanguage,.text[0:80]'
# With flag ON: responseLanguage = 'hi', text in Hindi.
# Expected by user: responseLanguage = 'en' (or mirror the majority script).
```

## Expected

For mixed input: either keep the response in the majority script's language, OR mirror the user's mixed scripts in the response. At minimum, count script characters and use the modal language, not first-match.
