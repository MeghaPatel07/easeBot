## Steps to reproduce
1. Tab A signed in. Tab B signed in. Same browser context.
2. In tab A, click "Sign in with Google" again (to refresh token) — this triggers `isHandlingAuth.current = true`.
3. During that window, tab B's `onAuthStateChanged` fires with the user (or null) — but `if (isHandlingAuth.current) return` SKIPS the handler.
4. After tab A completes, tab B's auth state is now wrong (showed old user even after Google flow finished).

## Expected
The `isHandlingAuth` guard exists to prevent re-entrant signup races in the SAME tab. It should not be cross-tab — but because `isHandlingAuth` is a `useRef` (per-tab), this is fine *in principle*. The actual bug: when signOut happens, `setProfile(null)` runs in the *signing-out* tab but NOT in the listening tab — because Firebase auth listener does fire null in other tabs, but only after the local persistence layer flushes. Test shows a 5-10s window where tab B retains profile + active query data.

## Expected
Logout should clear React Query cache + Zustand store + sessionStorage SESSION_KEY in EVERY tab inside 1 s of the originating tab firing `signOut()`.

## Actual
- `signOutUser` in `authService.ts:464-467` clears localStorage for the *current* tab only.
- Tab B's `onAuthStateChanged(null)` does fire — eventually — but `TanStack Query` cache holds `['account','me']`, `['account','usage']` data forever (no `qc.clear()` on logout).
- The `useUsageStats` query has `refetchInterval: 60_000` → in tab B, it keeps polling with the now-stale token, eventually 401-ing. Backend doesn't push a "logout-everywhere" signal.

## Impact
P0 — same shared-device / kiosk vulnerability as WE-20260528-552. Logged this separately because the fix is different: this is about `queryClient.clear()` and per-tab cleanup, not the storage-event signaling.

## Fix direction
- In `signOutUser` (authService.ts:455-470): call `queryClient.clear()` (need to expose via React tree or import lazily).
- In AuthContext, when `firebaseUser === null` and previous state had a user, call `qc.clear()` + `setProfile(null)`.
