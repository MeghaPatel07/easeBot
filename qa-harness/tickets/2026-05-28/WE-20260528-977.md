## Steps to reproduce
1. Open Personalization tab. Change wedding date to a far-future date.
2. While Network throttled to Offline, click Save.
3. Mutation rejects. Toast shows error.

## Expected
Form value reverts to the previously saved server value.

## Actual
- The `catch` in PersonalizationTab.tsx:150 (per grep) does roll back state, BUT the rollback uses the `profile` snapshot at the time the Save was clicked. If `profile` was already stale (per 152 + 161), the rollback writes the wrong "previous" value.
