## Description

Lighthouse reports 5 long-task entries on /chat initial load:
- 209ms Unattributable
- 136ms /assets/index-BFQDlZeM.js (vendor)
- 84ms Unattributable
- 74ms /assets/index-BFQDlZeM.js
- 63ms /assets/index-BFQDlZeM.js
Total = 566ms of main-thread blocking by long tasks alone.

A long task is any synchronous work >50ms; these starve the browser of input responsiveness and inflate INP. The bulk attributes to the vendor chunk (parse + execute of 1.2MB of JS).

## Steps to reproduce

1. npm run build && npx vite preview --port 4173
2. lighthouse with throttling=4x — see long-tasks audit

## Expected

Zero long tasks > 50ms during initial load (or only one ≤ 100ms).

## Actual

5 long tasks totaling 566ms+; user input during this window will register as 500ms+ INP.
