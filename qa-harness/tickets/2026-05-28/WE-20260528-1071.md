## Description

The 6 OTP digit inputs use `type="text" inputMode="numeric" maxLength={1}` — no `autocomplete="one-time-code"`. iOS Safari + macOS Safari + Android Chrome read SMS-delivered OTPs and offer auto-fill, but ONLY if the input is marked correctly. Without it, users with motor impairments, dyslexia, or older eyes (mistype) must visually parse the 6-digit code from another app/SMS and type each digit manually.

There's also a `handleFpOtpPaste` handler — good for keyboard-paste, but iOS one-time-code auto-fill is the platform standard the user expects.

## Expected

First input: `autoComplete="one-time-code"`. iOS/Safari will recognize the SMS code arrival and offer suggestion bar.

Manual transcription only.
