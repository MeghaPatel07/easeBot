## Description

Checkout displays "Billed in USD · locked at checkout · no refunds per terms §6.5". For a user with cognitive impairment, low literacy, or ESL background:
- "§6.5" is a legal symbol unfamiliar to most users
- "locked at checkout" is jargon
- "per terms" is not a link — the user can't actually go to terms section 6.5 directly

WCAG 3.1.5 wants reading level ≤ secondary education for content not requiring expertise. Legal/financial summary copy can be lower.

## Expected

- Rephrase: "Charged in USD at this price. Read our refund policy."
- Make "refund policy" a link directly to /terms#refunds (anchor link)
- Drop "§" symbol; use plain language

## Actual

Legal-formal copy + dead reference.
