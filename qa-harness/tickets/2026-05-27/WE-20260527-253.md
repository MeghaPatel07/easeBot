## Description

`Index.tsx` (which renders every primary route — chat, planner, budget, timeline, etc.) contains only `<h2>` and `<h3>` elements (lines 938, 1005, 1154, 1192, 1223, 1253, 1287, 1544). There is no `<h1>`. Pages should have exactly one `<h1>` describing the main content for screen-reader Rotor/heading navigation. Login, Privacy, NoteHeader use `<h1>` correctly — Index does not.

## Steps to reproduce

1. Open `/`
2. With VoiceOver, press VO+U → Headings list

## Expected

A single `<h1>` reflecting the current view ("Wedding Chat" / "Planner" / etc.) followed by descending heading levels.

## Actual

The list starts at h2 — the page lacks a top-level landmark heading, and section headings (Planner, Budget, Timeline) all live at h2 with no enclosing h1.

## Notes

Suggested fix: add a visually-hidden (`sr-only`) `<h1>` per route that reflects the active view, OR convert one existing h2 to h1 when it makes semantic sense.
