## Description

No `autoComplete=` attribute is set on any auth input. The codebase grep returns zero matches in `src/components/auth/`. WCAG 2.2 AA requires programmatic identification of common input purposes.

## Steps to reproduce

1. Open SignInModal email/password fields
2. Inspect attributes in DevTools

## Expected

- Email: `autoComplete="email"`
- Password (login): `autoComplete="current-password"`
- New password / Confirm password: `autoComplete="new-password"`
- Phone: `autoComplete="tel"`
- OTP: `autoComplete="one-time-code"`

## Actual

None of these attributes are present. Password managers, browser autofill, and SMS-OTP auto-fill all degrade.

## Notes

Practical secondary benefit: enables iOS SMS code autofill for the verification-code input.
