## Description

The per-thread overflow trigger uses `opacity-0 group-hover:opacity-100` to appear only on mouse-hover. This makes it:
1. Invisible to non-mouse users (keyboard, touch, assistive devices). Even after Tab-reaching it, the `opacity-0` keeps it visually hidden — focus is invisible.
2. Lacking an `aria-label` — the screen-reader user only hears "button".

Same pattern in NotesSidebar:512.

## Steps to reproduce

1. Tab from the thread list into the row
2. Try to open the per-thread menu without using a mouse

## Expected

The menu trigger is reachable, visible when focused, and announces e.g. "Thread options for '<title>'".

## Actual

Hidden under `opacity-0`; focus invisible; no name announced.

## Notes

Fix: add `group-focus-within:opacity-100`, plus `aria-label={`Options for ${thread.title}`}`.
