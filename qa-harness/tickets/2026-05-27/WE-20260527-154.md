## Steps to reproduce
1. Settings → AI Behavior → drag "Warm" from 50 → 100, save.
2. Without reloading, send a chat message.

## Expected
Backend receives new toneSettings; response feels warmer.

## Actual
- `savePersonalization` writes `toneSettings` directly to Firestore via `updateDoc` (settingsService.ts:9).
- AuthContext profile is one-shot getDoc — never refreshes.
- Any chat-send pipeline that reads `profile.toneSettings` from AuthContext sends stale values; backend uses the old tone.

## Impact
P1 — silent failure. User believes their save worked (toast confirms), but the AI behavior is unchanged.

## Fix direction
AuthContext onSnapshot. Identical root cause to WE-20260527-150/153.

## Evidence
- src/services/settingsService.ts:5-11
- src/pages/settings/tabs/AiBehaviorTab.tsx:104-116 (tone state lifted from profile, never refreshed by save)
- src/contexts/AuthContext.tsx:87-145

## Note (2026-05-27)
Likely closed by WE-20260527-170 PR — verify after merge. `AuthContext.profile.toneSettings` will now reflect the Firestore write within one snapshot tick; chat send pipeline reads fresh tone.
