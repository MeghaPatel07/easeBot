## Description

The BETA pill has both visible text "BETA" and `aria-label="Beta program info"`. When both are set, the aria-label overrides the visible text for screen-reader users, so the announce becomes "Beta program info, button" — but no separate description tells the user what they'll see when they click. Consider using `aria-describedby` instead.

## Steps to reproduce

1. `http://localhost:8081/`.
2. Inspect the BETA pill HTML.

## Expected

Either visible text alone (sufficient labelling) or `aria-label` matches the visible text.

## Actual

Mismatched.

## Evidence

- Aria enumeration in `qa-explore.mjs`.
