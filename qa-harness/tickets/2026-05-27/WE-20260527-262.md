## Description

Each liked-message card is a `<div role="button" tabIndex={0} onClick={…} onKeyDown={…}>` (Enter/Space handled). It works but native `<button>` would inherit free focus styling, default Space-bar prevention, and `disabled` semantics. Also containing card has no accessible name — only inner text. Each card has heavy rendered markdown content; SR users hear the full content as the button name on focus.

## Steps to reproduce

1. Sign in, like a message, navigate to `/:userId/liked`
2. Tab to cards with VoiceOver

## Expected

Native `<button>` with `aria-label="Open conversation: <thread title>, mode: <mode>"`.

## Actual

`role="button"` div whose accessible name is the entire markdown preview.

Same pattern probably repeats in PlannerView.tsx:228, TimelineView.tsx:808 (also `tabIndex={0}` divs). Audit those.
