## Description

The mode-dropdown trigger (Auto / Stylist / Planner / etc.) is a `<button onClick={() => setShowModeDropdown(v => !v)}>` with NO `aria-haspopup="listbox"`, NO `aria-expanded`, NO `aria-controls`. The popover items (line 156) are buttons but without `role="option"` or `aria-selected`. Keyboard arrow-key navigation between modes is also not implemented — only click + Tab.

## Steps to reproduce

1. Tab to the mode chip
2. Press Enter; then try arrow-down to highlight the next mode

## Expected

Native combobox-style behaviour: aria-haspopup, aria-expanded toggles true on open, arrow keys move highlight, Enter selects, Escape closes.

## Actual

State changes work via click, but SR users get no signal that this is a menu, and keyboard navigation within the popover is broken.

## Notes

Easiest fix: use `@radix-ui/react-select` or `@radix-ui/react-popover` + `menu`/`listbox` roles instead of bespoke state.
