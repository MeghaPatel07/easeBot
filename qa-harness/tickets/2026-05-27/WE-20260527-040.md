## Description

After the failed image-gen attempt, the AI bubble shows "Something went wrong. Please try again." — but is still followed by "Shorter / Longer / Simpler / More formal" reframe chips and the "Auto" mode pill. These reframe controls have no meaningful action against a failed/error response — clicking "Shorter" cannot make the failure shorter.

## Steps to reproduce

1. `http://localhost:8081/` → request image gen that fails (~110s wait → "Something went wrong").
2. Look at the bubble — chips are still rendered.

## Expected

For error responses (`type === 'error'` in the message store), the reframe chips are suppressed. Instead show "Retry" only.

## Actual

Reframe chips render unconditionally.

## Evidence

- `qa-img.mjs` FINAL_BODY dump includes "Shorter Longer Simpler More formal" below the error.

## Notes

Same defect probably surfaces for any future error path (model-refusal, quota-exceeded, server-down).
