## Steps to reproduce
1. Settings → Account → change phone country code or national number, save.
2. Stay on page.
3. Trigger any external profile change (e.g., open another component that triggers `useAccount` refetch).

## Expected
Local form keeps the user's just-saved value.

## Actual
- AccountTab line 154-159 useEffect resets local state from `profile?.uid, profile?.name, profile?.nickname, derivedPhone.cc, derivedPhone.nat` whenever profile changes.
- If profile updates partially (e.g., from AuthContext) before phone fields land back from useAccount, the local form may transiently revert.
- Subtle but observable in slow networks.

## Impact
P2 — edge case but indicates form-state coupling to two different sources of truth.

## Fix direction
After save success, take a clean snapshot. Don't reset local state on every profile change — only on `profile?.uid` change.

## Evidence
- src/pages/settings/tabs/AccountTab.tsx:154-159 (over-broad effect deps)
