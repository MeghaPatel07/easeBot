## Description

Generated/attached images in the chat use weak alt values:
- ChatMessages.tsx:366 — `alt="Attached"`
- ChatMessages.tsx:470 — `alt={alt ?? ''}` (markdown-fed; empty string for AI-generated images effectively hides them)
- ChatMessages.tsx:582 — `alt="Generating..."` (acceptable for streaming state but never updated when final image arrives)
- GalleryView.tsx:156/237 — `alt={img.prompt || 'Generated image'}` (good when prompt exists, but falls back to generic "Generated image" — should at least cite mode/style)

For AI image responses, the original prompt or a model-supplied caption should populate `alt`. Empty/generic alts are equivalent to decorative — screen-reader users see nothing useful.

## Steps to reproduce

1. Ask the bot to generate an image
2. Inspect the resulting `<img>` alt attribute

## Expected

`alt={message.prompt || message.caption}` — non-empty, meaningful description of the generated image's content.

## Actual

Empty or generic alt strings.

## Notes

The avatar `<img src={easebotAvatar} alt="" />` (ChatMessages:428) IS correctly decorative — that one is fine. Focus the fix on user-uploaded and AI-generated image renderings.
