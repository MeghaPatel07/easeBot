## Description

The base Button variant uses `focus-visible:ring-1 focus-visible:ring-foreground/10` — a single-pixel ring at 10% foreground opacity. Against the background this fails 3:1 contrast in BOTH light and dark themes and is effectively invisible. Keyboard-only users cannot track focus.

Additionally many bespoke buttons in `ChatInput`, `ChatHeader`, `ChatSidebar`, `SettingsModal` use `focus:outline-none` without any compensating `focus-visible:ring-…` — wiping the browser default ring entirely (see grep below).

## Steps to reproduce

1. Hide your mouse, Tab around the chat shell
2. Watch for visible focus indicators

## Expected

A clearly visible 2px ring with ≥3:1 contrast on every focusable element.

## Actual

Focus is invisible or barely visible. Some buttons (ChatInput Send, Mic, Stop, mode dropdown) have no ring at all.

## Notes

Suggested ring spec: `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background`. Audit all `focus:outline-none` occurrences and pair with `focus-visible:ring-*`. Files with bare `focus:outline-none`:
- ChatInput.tsx, ChatHeader.tsx, ChatSidebar.tsx, SettingsModal.tsx, InvitePartner.tsx, VibeComposer.tsx, GalleryFilterBar.tsx, SignInModal.tsx, SignUpModal.tsx.
