## Description

The empty-state hero banner "Not sure where to start? … [Help me decide]" is rendered with `hidden sm:flex`, so mobile users (where the AI-led onboarding affordance is arguably most important) never see the prominent "Help me decide" CTA. The four small action cards survive, but the unified entry point doesn't.

## Steps to reproduce

1. Open `http://localhost:8081/` in a 375×667 viewport (iPhone SE / Playwright `isMobile: true`).
2. Dismiss consent.
3. Inspect the empty state.

## Expected

The "Help me decide" CTA banner is visible on mobile (or replaced with a mobile-tuned equivalent that surfaces the same prompt). Per walkthroughpoints.md, the starting prompt options should be the most-useful onboarding element.

## Actual

Only four small cards render: "What should I get", "Help me plan", "Show me ideas", "Ask anything". The "Help me decide" hero CTA is absent.

## Evidence

- Screenshot: `qa-harness/evidence/WE-20260527-005/screenshots/mobile-home.png`

## Notes

Either drop the `hidden sm:flex` guard or render a compact mobile variant.
