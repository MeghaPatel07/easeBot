## Description

DOM probe shows two `<button aria-label="Attach">` elements on the home page. Screen readers will announce the same button twice, and tab-order will visit a hidden duplicate. One is likely the mobile variant, the other desktop, but both ship without any visual differentiation in DOM.

## Steps to reproduce

1. Open `http://localhost:8081/`.
2. In DevTools console: `document.querySelectorAll('button[aria-label="Attach"]').length` → returns `2`.

## Expected

A single attach button (responsive via CSS), or two buttons with distinct context (e.g. `aria-label="Attach image (mobile)"`).

## Actual

Two identical Attach buttons — see WE-20260527-007 for the visibility problem; this is the structural cause.

## Evidence

- `qa-deep2.mjs` aria-label enumeration: `["…","Attach","Attach"]`.

## Notes

Consider conditional render via single source-of-truth + Tailwind responsive classes, not two siblings.
