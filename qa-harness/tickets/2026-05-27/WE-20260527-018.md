## Description

Button enumeration of the home page lists `"Auto"` twice as separate buttons (`btn[35]` and `btn[38]`). Without aria-labels disambiguating them, a screen-reader user hears "Auto button, Auto button" with no context.

Per `modeRouter.ts`, "Auto" is the mode-select default — but it should appear once.

## Steps to reproduce

1. `http://localhost:8081/`.
2. Console: `[...document.querySelectorAll('button')].filter(b => b.innerText.trim() === 'Auto').length` → returns `2`.

## Expected

Single button, or two with disambiguated labels (e.g. `Auto language` vs `Auto mode`).

## Actual

Two identical buttons; one is the mode pill, one is likely the language fallback. Confusing for keyboard / screen-reader users.

## Evidence

- `qa-modes.mjs` ALL_BUTTONS enumeration.

## Notes

Likely the language pill and the mode pill both say "Auto" in their default state.
