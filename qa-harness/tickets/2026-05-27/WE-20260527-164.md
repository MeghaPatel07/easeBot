## Steps to reproduce
1. Open same chat in two tabs.
2. Tab A — like a product card.
3. Tab B — view same product card; like it.

## Expected
The product is liked once. Both tabs converge to the same set.

## Actual
- `useChat` line 260 subscribes via `subscribeToLikedProducts(user.uid, setLikedProducts)`. Good — that's a Firestore listener.
- Toggle path lines 270-278 doesn't optimistically update; the round-trip is the source of truth. So convergence works.
- BUT: optimistic UI is absent — for ~200-500ms the like button feels unresponsive. Not strictly a sync bug, but a polish gap.

## Impact
P2 — minor UX friction.

## Fix direction
Add optimistic `setLikedProducts` before the await, rollback in catch.

- src/hooks/useChat.ts:257-296
