# WE-20260527-307 — Existing `utils/dynamicImports.ts` is dead code — clean up or wire up

**Severity:** P3

**Area:** Code hygiene / Performance latent fix
**File:** `Wedding-Ease-Viva-Chat/src/utils/dynamicImports.ts`
**Discovered:** 2026-05-27

## Symptom
`src/utils/dynamicImports.ts` exports 8 `React.lazy()`-wrapped components:
`LazyBudgetDashboard, LazyShoppingListView, LazyTimelineView, LazyProgressDashboard, LazyComparisonTable, LazyGalleryView, LazyChecklistDetail, LazySettingsModal`.

`grep -rn "LazyBudgetDashboard|LazyShoppingListView|..." src/` returns **0 imports anywhere outside the definition file**. The file is dead code.

Meanwhile, `pages/Index.tsx` statically imports all the un-lazy versions of those same components (see WE-20260527-301).

## Suggested fix
This ticket is the cleanup tail of WE-20260527-301. Once Index is migrated to use the Lazy* variants:
- Verify every Lazy* export is consumed.
- Remove unused ones (e.g. `LazyComparisonTable` is only used inside a markdown table renderer — likely a no-op).
- Add a brief comment explaining the lazy-loading pattern so future contributors don't undo it by adding a static import "for convenience".

Don't fix this independently — it's a follow-on to WE-20260527-301. File now so it isn't forgotten.
