## Description

17 icon-only buttons across ChatHeader / ChatSidebar use only `title="…"` for their name:
- "Open sidebar" / "Close sidebar" (PanelLeft icon)
- "New Chat" (SquarePen icon) — two locations
- "Search chats" / "Chat search — upgrade to Pro" (Search icon)
- "Settings" trigger on ProfileIcon (line 82)
- Per-thread overflow menu trigger (ChatSidebar:210)

These should expose programmatic names via `aria-label`. Many sit in the primary navigation path so screen-reader users can't reliably operate the chat shell.

## Steps to reproduce

1. Enable VoiceOver
2. Tab through the sidebar and header
3. Note which buttons announce only "button" with no name

## Expected

Each button announces a meaningful name.

## Actual

Buttons announce "button" — name is delivered only through the visual `title` tooltip.

## Notes

Bulk fix: replace `title="X"` with `aria-label="X" title="X"` (keep title for sighted hover hint).
