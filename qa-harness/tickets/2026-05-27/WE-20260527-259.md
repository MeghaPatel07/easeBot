## Description

There is no "Skip to main content" link as the first focusable element. Grep finds zero matches for `skip*link` / `Skip to` / `<a href="#main"`. Keyboard users opening the chat must Tab through the full sidebar (~10–15 stops including thread list) every navigation before reaching the input.

## Steps to reproduce

1. Load `/`
2. Press Tab once

## Expected

The first focusable element is a "Skip to main content" link that jumps focus to `<main>` / chat input.

## Actual

Focus enters the sidebar or top-left logo and walks through every link/button.

## Notes

Add at root of layout:
```jsx
<a href="#main" className="sr-only focus:not-sr-only focus:absolute focus:top-2 focus:left-2 …">Skip to main content</a>
```
And add `id="main"` to the existing `<main>` elements in Index.tsx (already present, lines 1186, 1217, 1399, 1516 — just need ids).
