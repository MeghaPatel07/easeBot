## Description

Every page load logs two PostHog 404s plus a MIME-type console error. PostHog config endpoint `/ingest/array/phc_.../config.js` (and `/config?ip=0&...`) returns 404 because there is no Vite dev proxy or backend route at `/ingest`. With `VITE_POSTHOG_HOST` defaulting to `/ingest` (`src/lib/analytics.ts:163`), all analytics fetches fail in dev. Feature flags, capture events, and session recordings cannot reach PostHog, so any logic in `useFeatureFlag.ts` will fall back to defaults.

## Steps to reproduce

1. `cd Wedding-Ease-Viva-Chat && npm run dev` (already up at :8081).
2. Open `http://localhost:8081/` in any browser or via Playwright with console + network capture.
3. Observe network panel.

## Expected

PostHog client either loads from a configured proxy/host or is disabled cleanly (no console errors when `VITE_POSTHOG_ENABLED !== 'true'`).

## Actual

Two requests fail with HTTP 404 on every page:
- `GET /ingest/array/phc_C3dxDiWMwVzdTWbXbDXvp98L9XCm2qFTJtcgxenkkBXV/config.js` → 404
- `GET /ingest/array/phc_.../config?ip=0&_=<ts>&ver=1.369.3` → 404

Console:
```
Refused to execute script from 'http://localhost:8081/ingest/array/phc_C3dxDiWMwVzdTWbXbDXvp98L9XCm2qFTJtcgxenkkBXV/config.js' because its MIME type ('') is not executable, and strict MIME type checking is enabled.
```

Repeats on `/`, `/login`, `/pricing`, `/help`, `/terms`, `/privacy`, `/share/*`, `/shared/note/*` — i.e. everywhere.

## Evidence

- Screenshot(s): `qa-harness/evidence/WE-20260527-001/screenshots/`
- Console + network captured via Playwright (`Wedding-Ease-Viva-Chat/qa-explore.mjs`)

## Notes

Likely fixes:
- Configure Vite dev proxy: `'/ingest': { target: 'https://us.i.posthog.com', changeOrigin: true, rewrite: p => p.replace(/^\/ingest/, '') }`.
- Or set `VITE_POSTHOG_HOST=https://us.i.posthog.com` for dev.
- Or short-circuit `analytics.ts` when `import.meta.env.DEV && !VITE_POSTHOG_ENABLED` to avoid the bootstrap fetch.

Impacts: feature flags evaluate as false, no session recording, no funnel data. Polluted console makes other regressions harder to spot.
