## Description

`index.html` preloads `/images/IMG_3917.PNG` but the asset is never referenced (no `img src=` or `background-image` URL matches). Browser warns:

```
The resource http://localhost:8081/images/IMG_3917.PNG was preloaded using link preload but not used within a few seconds from the window's load event.
```

Wastes ~hundreds of KB on every visitor's first load.

## Steps to reproduce

1. Load any route, e.g. `http://localhost:8081/`.
2. Open Network → filter for `IMG_3917`.
3. Console warning fires within 4 s of load.

## Expected

Remove the preload (the comment in `index.html` says "Preload background image for immediate loading" — but nothing in the rendered DOM uses it) or wire the asset to whatever it was intended to back.

## Actual

Preloaded → never used → console warning.

## Evidence

- Console captured in `qa-lastchecks.mjs`.

## Notes

Could be a leftover from a previous design iteration.
