## Description

PRD-BugsFixes 5.3 / 5.4 discuss stop-generation behaviour for image generation but image generation is broken (see WE-20260527-002), so stop-during-image is moot. For text generation, a streaming SSE reply takes 2-4 seconds. During that window there's no visible "Stop generating" button. If the assistant goes off-topic or the user changes their mind they have no recourse but to wait.

## Steps to reproduce

1. `http://localhost:8081/`, send "Write me a 500-word detailed plan for a December Goa wedding with all logistics."
2. Watch the streaming response.

## Expected

While streaming, the Send icon becomes a square/stop icon. Clicking it aborts the SSE stream and prints "*Response interrupted*".

## Actual

No visible stop affordance. Send button (already missing aria — WE-20260527-009) is the only control.

## Evidence

- `qa-chips.mjs` screenshot during streaming shows no stop button.

## Notes

PRD-BugsFixes 5.3 says interrupted messages should save with the suffix "The response was interrupted". Both surfaces (text + image) need a stop UX.
