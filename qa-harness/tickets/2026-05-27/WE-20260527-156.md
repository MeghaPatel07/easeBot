## Steps to reproduce
1. Open two tabs in the same browser context, same user signed in.
2. Tab A — Settings → change Display Name, save.
3. Tab B — observe sidebar / profile menu / chat header.

## Expected
Tab B updates within ~1s.

## Actual
Tab B never updates until you reload it.

Reasons:
- No `BroadcastChannel`, no `window.addEventListener('storage', …)`, no Firestore `onSnapshot` on the user doc. Confirmed by grep: `BroadcastChannel`, `storage event`, `cross-tab` return zero matches in src/.
- TanStack Query cache is per-tab; invalidation in Tab A doesn't reach Tab B.
- Even theme switch (ThemeContext line 116-118) is fire-and-forget; localStorage write happens, but storage event listener does not exist to apply it in Tab B.

## Impact
P1 — affects every state field. The token meter, tier badge, theme, name, tone, voice — none cross-tab sync.

## Fix direction
Either: (a) AuthContext.onSnapshot — Firestore will push to all tabs naturally; (b) a `BroadcastChannel('account')` and listener in AuthContext to apply updates.

## Evidence
- grep BroadcastChannel — 0 matches
- grep "storage.*event" — 0 matches
- src/contexts/AuthContext.tsx — onAuthStateChanged only
- src/contexts/ThemeContext.tsx:116-118 — writes localStorage but no listener picks it up cross-tab
