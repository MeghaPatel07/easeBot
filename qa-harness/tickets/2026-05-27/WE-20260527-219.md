## Description

Express's default `express.json()` middleware returns the JSON-parser exception verbatim. A POST with body `this is not json at all` yields:
```json
{"error":"Unexpected token 't', \"this is no\"... is not valid JSON","code":"INTERNAL_ERROR"}
```

This echoes the first 10 bytes of the user's body. If a fuzzer is probing the API, the response confirms what they sent and at what offset the parser bailed — useful reconnaissance.

## Steps to reproduce

```bash
curl -X POST http://localhost:3001/api/chat -H "Content-Type: application/json" --data-binary 'this is not json at all'
```

## Expected

`400 { "error": "Malformed JSON request body", "code": "BAD_REQUEST" }` — no echo of the original bytes.

## Actual

Bytes from input body included in error message.

## Evidence

- `qa-harness/evidence/WE-20260527-219/curl.log`

## Notes

Use a custom JSON parse-error handler:
```ts
app.use((err, req, res, next) => {
  if (err.type === 'entity.parse.failed') return res.status(400).json({ error: 'Malformed JSON', code: 'BAD_REQUEST' })
  next(err)
})
```
