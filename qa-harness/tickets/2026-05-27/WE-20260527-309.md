# WE-20260527-309 — Vendor bundle is 1.2 MB / 331 kB gzip with no manualChunks strategy

**Severity:** P2
**Status:** triaged
**Assigned:** fix-performance
**Area:** Performance / Bundle splitting
**File:** `Wedding-Ease-Viva-Chat/vite.config.ts` (missing `build.rollupOptions.output.manualChunks`)
**Discovered:** 2026-05-27

## Symptom
Vite build emits:
```
dist/assets/index-BFQDlZeM.js   1,196.48 kB │ gzip: 331.01 kB   ← vendor + framework
dist/assets/Index-BI9zObHt.js   1,316.92 kB │ gzip: 354.70 kB   ← app
```

Plus a warning: "Some chunks are larger than 500 kB after minification."

The vendor chunk dumps everything non-`./src/` into one file — React, react-dom, react-router, @tanstack/react-query, posthog-js, firebase, all 30+ Radix UI primitives, react-markdown, remark-gfm, all Lucide icons, dompurify, etc.

A user only needs Radix Dialog + Dropdown + Tooltip + ScrollArea on the home view. Loading the full Radix barrel and all of `lucide-react` per cold start is wasted work.

## Suggested fix
Add a basic manualChunks split:
```ts
build: {
  sourcemap: 'hidden',
  rollupOptions: {
    output: {
      manualChunks: {
        'react-vendor': ['react', 'react-dom', 'react-router-dom'],
        'fb-app': ['firebase/app', 'firebase/auth'],
        'fb-data': ['firebase/firestore', 'firebase/storage'],
        'query': ['@tanstack/react-query'],
        'analytics': ['posthog-js'],
      },
    },
  },
}
```

Then run `npx vite-bundle-visualizer` and split further as needed. Firebase alone is typically 200 kB+ — should be its own cacheable chunk.

## Suggested verification
After change, no individual non-page chunk should exceed 150 kB gzipped.
