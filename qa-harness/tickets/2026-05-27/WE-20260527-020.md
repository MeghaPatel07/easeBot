## Description

The Send button has no aria-label and no visible disabled state. We could not confirm via DOM whether it has a `disabled` attribute. Pressing Enter with empty textarea also has not been confirmed to be a no-op. Spec checklist item: "Send button disabled when input empty."

## Steps to reproduce

1. `http://localhost:8081/`, dismiss consent.
2. Focus the textarea (do not type).
3. Press Enter.

## Expected

No request to `POST /api/chat/stream`. The Send icon is visibly disabled (greyed). `aria-disabled="true"`.

## Actual

Unknown — there is no aria-labelled "Send" button to probe. The textarea-focused Enter must be inspected, but missing aria makes the contract opaque.

## Evidence

- See `qa-deep2.mjs` SEND_STATE_BEFORE / AFTER (empty arrays).

## Notes

Combined with WE-20260527-009 (missing aria-label). Add proper a11y first, then verify the disabled contract.
