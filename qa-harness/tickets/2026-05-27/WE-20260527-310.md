# WE-20260527-310 — CSS bundle is 189 kB (28 kB gzip) — Tailwind purge may be misconfigured

**Severity:** P3
**Status:** triaged
**Assigned:** fix-performance
**Area:** Performance / CSS
**File:** `Wedding-Ease-Viva-Chat/dist/assets/index-BFm3j64I.css`
**Discovered:** 2026-05-27

## Symptom
Single CSS bundle ships at **189.30 kB raw / 28.19 kB gzip**. For a SPA that primarily uses Tailwind utility classes, this is high — Tailwind+shadcn projects typically ship 15-25 kB gzip when purge is working.

Lighthouse render-blocking-resources flags this CSS as costing **459 ms** of wasted critical-path time on cold load.

## Suggested fix
1. Confirm `tailwind.config.ts` `content:` glob covers every `.tsx`/`.ts` file but excludes node_modules.
2. Audit `src/index.css` for any global rules / `@layer base` declarations that pull in heavy fonts or base styles for components not used.
3. Run `npx unused-css` or PurgeCSS in CI to spot regressions.
4. The biggest win is usually CSS-in-JS leakage from libs — check if any Radix primitives are bringing their own stylesheets.

## Suggested verification
Target less than 20 kB gzipped CSS post-fix.
