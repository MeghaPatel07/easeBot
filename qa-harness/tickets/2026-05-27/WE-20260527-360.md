## Description
Query "My wedding is in 6 months — what should I do now?" should classify as `planner` (explicit time-bound, asks for next steps). It scored 0 across all modes because the planner regex on line 21 matches `\bmonths? (before|away)\b` — the user wrote "in 6 months" not "6 months before/away". The fallback then routed to `assistant`. The assistant response was reasonable but lost the planner-specific timeline guidance (numbered checklist, 12-6-3-1 milestones).

## Steps to reproduce
1. `curl -X POST http://localhost:3001/api/chat -d '{"message":"My wedding is in 6 months — what should I do now?"}'` → `mode=assistant`.

## Expected
`mode=planner` — user has a deadline and asks for action items.

## Actual
`mode=assistant`. Planner-specific structure (numbered milestones, time brackets, save-to-checklist offer) absent.

## Notes
Add `in \d+ months?\b` to the planner regex. Also covers "in 3 weeks", "in 2 months", etc.
