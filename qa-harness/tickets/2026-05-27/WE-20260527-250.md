## Description

The primary Send, Stop-generating, and Mic buttons in `ChatInput` are icon-only and have only a `title=` attribute — no `aria-label`. Screen readers (VoiceOver/NVDA) frequently do NOT announce `title` (especially on touch devices and depending on verbosity settings), so the AT user hears nothing or hears generic "button". This effectively blocks message submission for non-sighted users — the most important interaction on the page.

Affected buttons:
- Send (line 474, only `title="Send"`)
- Stop (line 466, only `title="Stop generating"`)
- Mic (line 434, only dynamic `title=`)

The mode-dropdown trigger and attachment expand toggle have the same issue.

## Steps to reproduce

1. Enable VoiceOver (Cmd+F5)
2. Tab to the send/mic/stop buttons in the input pill
3. Listen to the announcement

## Expected

Each button announces a clear name (e.g. "Send message, button", "Record voice message, button", "Stop generating, button").

## Actual

VoiceOver announces "button" or nothing meaningful — no accessible name.

## Notes

`title` is a visual tooltip, not an accessible name. The voice-recording path (lines 258-345) correctly uses `aria-label`. Apply the same to the idle-mode Send/Stop/Mic buttons.
