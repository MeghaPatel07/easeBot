## Description

Two issues in `SettingsModal`:

1. **Missing `DialogDescription`** — Radix Dialog logs a console warning when omitted, and screen readers lose the modal's purpose summary. Only `DialogTitle.sr-only="Personalization settings"` is present.
2. **Tabs are styled `<button>`s, not WAI-ARIA tabs** — The Identity/Tone/Voice tabs (line 181-194) have no `role="tablist"` / `role="tab"` / `aria-selected` / `aria-controls`. Arrow-key navigation between tabs (expected for tab widgets) doesn't work. Screen readers announce 3 unrelated buttons.

## Steps to reproduce

1. Open Settings from the sidebar
2. Press Tab; arrow-Right after the first tab

## Expected

Tabs are announced as "tab, 1 of 3, selected"; arrow keys move between them; `aria-controls` points to the panel. Dialog narrates a description.

## Actual

Tabs are generic buttons; arrow keys do nothing; dialog has no descriptive subtitle exposed to AT.

## Notes

Use `@radix-ui/react-tabs` (already in shadcn). Add `DialogDescription` (can be `sr-only`).
