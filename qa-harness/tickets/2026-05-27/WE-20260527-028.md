## Description

Querying `[role="tab"]` on the settings modal returns six entries:
```
["AI Behavior","Data & Privacy","About","AI Behavior","Data & Privacy","About"]
```
i.e. each tab is rendered twice (probably a mobile drawer + desktop sidebar both mounted). Screen readers will announce six tabs.

## Steps to reproduce

1. `http://localhost:8081/?settings=account`.
2. Console: `document.querySelectorAll('[role="tab"]').length`.

## Expected

Three tabs, with one variant hidden via Tailwind responsive classes — but the duplicates should NOT both carry `role="tab"`.

## Actual

Six `role="tab"` elements on one screen.

## Evidence

- `qa-settings.mjs` TABS enumeration.

## Notes

Hide the unused variant from accessibility tree via `aria-hidden="true"` on the wrapper, or render conditionally.
