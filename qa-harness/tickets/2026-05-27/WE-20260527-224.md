## Description

`grep navigator.onLine` returns 0 hits across `src/`. No service worker. No PWA config (`vite-plugin-pwa` absent). Effects:

- Mid-flight requests during a network blip fail with raw fetch errors.
- A returning user offline sees a blank Vite page (no app-shell cached).
- Saved checklists / notes are not available without network.
- The chat history (cached locally for some flows) cannot fall back to a "you're offline" empty state.

For a planning app where couples scroll their planner on the move (subway, venue tours), this is a usability gap.

## Steps to reproduce

1. Load app. Disconnect network.
2. Refresh the tab.

## Expected

- Service worker pre-caches the app shell so refresh works offline (showing an "offline" banner over cached content).
- `navigator.onLine` + `window.addEventListener('online'|'offline', ...)` to toast state changes.
- Optimistic message queue that drains on reconnect.

## Actual

Blank page on offline refresh; mid-flight requests just fail.
