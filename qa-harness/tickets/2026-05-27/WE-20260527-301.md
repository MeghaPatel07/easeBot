# WE-20260527-301 — Index.tsx (1668 LOC) static-imports every heavy view, defeats the existing lazy infrastructure

**Severity:** P1
**Status:** triaged
**Assigned:** fix-performance
**Area:** Performance / Bundle splitting
**File:** `Wedding-Ease-Viva-Chat/src/pages/Index.tsx`
**Discovered:** 2026-05-27

## Symptom
The largest production chunk is `Index-BI9zObHt.js` at **1,316.92 kB (354.7 kB gzipped)** — well over the 250 kB main-bundle threshold from the QA brief and 7x the "good" 200 kB initial-JS target.

Lighthouse reports **256 kB of unused JavaScript inside this chunk** on the empty-state route — the user hasn't even opened a sidebar view yet, but they have downloaded:
- BudgetDashboard.tsx (414 LOC)
- ShoppingListView.tsx (637 LOC)
- TimelineView.tsx (1006 LOC)
- ProgressDashboard.tsx (302 LOC)
- ChecklistDetail.tsx (484 LOC)
- GalleryView, SavedItemsView, RemindersView, NotificationPanel, InvitePartner, etc.

## Root cause
`src/utils/dynamicImports.ts` defines `LazyBudgetDashboard`, `LazyShoppingListView`, `LazyTimelineView`, `LazyProgressDashboard`, `LazyComparisonTable`, `LazyGalleryView`, `LazyChecklistDetail`, `LazySettingsModal` — all React.lazy wrappers — but **none of them are imported anywhere in `src/`** (verified via `grep -rn "LazyBudgetDashboard" src/`). They are dead exports.

`pages/Index.tsx` instead does static imports (lines 26-43):
```ts
import PlannerView from '@/components/PlannerView';
import ChecklistDetail from '@/components/ChecklistDetail';
import BudgetDashboard from '@/components/BudgetDashboard';
import ShoppingListView from '@/components/ShoppingListView';
import SavedItemsView from '@/components/SavedItemsView';
import TimelineView from '@/components/TimelineView';
import RemindersView from '@/components/RemindersView';
import GalleryView from '@/components/GalleryView';
import ImagesHub from '@/pages/ImagesHub';
import NotesView from '@/components/notes/NotesView';
import ProgressDashboard from '@/components/ProgressDashboard';
import NotificationPanel from '@/components/NotificationPanel';
import InvitePartner from '@/components/InvitePartner';
```

Each view is only rendered when `sidebarView === '<x>'` — perfect lazy-load candidates.

## Suggested fix
1. In `pages/Index.tsx`, replace the static imports with the existing `Lazy*` exports from `utils/dynamicImports.ts`.
2. Wrap the conditional `mainAreaShell` calls in a per-view `<Suspense fallback={<LoadingScreen />}>` boundary (the route-level Suspense is fine for first paint but a per-view one keeps the chat surface interactive).
3. Confirm with `npm run build`: Index chunk should drop below 200 kB gzipped, and Budget/Timeline/Notes should appear as separate chunks.

Expected outcome: initial JS on `/` drops from 354 kB gzipped to ~150 kB gzipped, LCP recovers to < 4s.
