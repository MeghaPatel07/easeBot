## Description

DOM image scan shows `<img src="http://localhost:8081/src/assets/images/Wedding%20ease.png">`. The asset filename contains a space which is URL-encoded as `%20`. Spaces in asset filenames cause:
- Inconsistent caching keys across CDNs
- Brittle integration with tools that don't url-decode (some bundlers, some CDN purge tools)
- Confusing diff-and-search

Should be `wedding-ease.png` or `weddingEase.png`.

## Steps to reproduce

1. `http://localhost:8081/`.
2. Inspect `<img>` tags. Note `Wedding%20ease.png`.

## Expected

Renamed asset (no spaces).

## Actual

Asset has a space in the filename.

## Evidence

- `qa-img.mjs` polled image src list.

## Notes

Trivial rename + update imports.
