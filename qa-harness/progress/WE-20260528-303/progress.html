Bug summary

Index.tsx (1668 lines) is a god-component used by every primary route. It statically imports 14+ heavy view modules (BudgetDashboard, TimelineView, ShoppingListView, PlannerView, etc). Build emits a single Index chunk of ~583 KB raw / ~142 KB gz that ships on every route. Lighthouse reports 250 KB (72%) of this chunk is unused on /chat. PR #49 (WE-20260528-304) already lazies NotesView; this PR lazies the remaining views, complementing #49.
