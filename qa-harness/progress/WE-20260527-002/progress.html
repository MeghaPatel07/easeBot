WE-20260527-002 · Image generation never completes — "Something went wrong" after >2 min P0

Repo: easebot-backend · Agent: fix-backend-api · Branch: fix-WE-20260527-002 → Bug-Resolve-claude · Worktree: worktrees/fix-WE-20260527-002

Bug summary

Guest sends "Generate an image of pastel mandap with white roses". Bubble shows "generating..." then ~110s later swaps to generic "Something went wrong. Please try again." No image renders, no actionable error code surfaced. Diagnosis: the Azure image-generation REST fetch has no explicit timeout. When Azure hangs (or replies slowly enough that the client/proxy aborts first), fetch() waits indefinitely; the client AbortController eventually fires at ~110s, the inner callAzureImageGeneration throws AbortError, retry/fallback chain rolls through, and the stream terminates with the generic { t: 'e' } envelope that the frontend renders as the catch-all error string.

Root cause located in callAzureImageGeneration (line 313) and callAzureImageEdit (line 456).
