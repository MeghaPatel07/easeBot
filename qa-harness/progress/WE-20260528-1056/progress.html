WE-20260528-1056 · Per-message lang + dir attributes for non-English chat content P1

Bug summary

App declares <html lang="en"> permanently in index.html. The chat backend correctly detects/returns a BCP-47 language per message (Hindi, Gujarati, Arabic, Spanish, French, etc.), but the AI message <div> wrapping message.content never gets a corresponding lang= attribute. Result: NVDA / VoiceOver read Hindi or Arabic text using English phonemes — garbled, incomprehensible. WCAG 3.1.2 Language of Parts (AA) failure. Arabic also renders LTR — visually + audibly jarring.
