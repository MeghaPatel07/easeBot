Bug summary

BudgetDashboard footer renders percentage-used and amount-remaining chips. When budget.categories.length === 0 (fresh user / empty state), totalSpent is 0 and remaining = totalBudget - 0 = totalBudget, and overallPct falls back to 0 (since totalBudget may be 0 too). The footer displays 0% used and $0 left as literal values. This is technically true but semantically misleading — "0% of nothing" reads as "you've spent nothing of your budget" when there's actually no budget defined yet. The left side of the footer already handles the empty state with "Add categories to start tracking", but the right-side chips do not.
