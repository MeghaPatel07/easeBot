Bug summary

When wedding planners share a chat transcript or a note with their client via /share/:token or /shared/note/:token, hitting Cmd+P generates a PDF that includes the decorative app gradient, fixed global elements (analytics consent banner, cap-hit banner, toasts), the sticky in-page header with a "create your own" CTA, and message bubbles that split mid-sentence across page breaks. The result is ink-wasting, hard-to-read, and unsuitable for client handoff. No @media print block exists anywhere in src/ (grep confirmed zero matches).

Audit trail

2026-05-29 setup
Created worktree from origin/Bug-Resolve-claude as branch fix-WE-20260528-864.
2026-05-29 diagnose
Inventoried decorative chrome on the shared pages.
SharedChat uses .gradient-bg which carries decorative ::before (grid) and ::after (radial bloom) layers. SharedNote uses bg-surface-note (a deep wine surface) which prints as a dark page. App.tsx renders CapHitBanner, AnalyticsConsent, Toaster, Sonner globally — all position: fixed. GlobalFloater is already correctly excluded from /share/* routes. Sticky page headers and the "Create your own wedding notes" CTA also need to be hidden in print.
2026-05-29 design
Chose hybrid approach: marker class .shared-print-surface on page roots + single @media print block in src/index.css, plus Tailwind print:hidden / print:break-inside-avoid on inline elements.
Reasoning: Tailwind print: alone cannot neutralize ::before / ::after pseudo-elements on .gradient-bg nor reach the globally-mounted fixed children that live outside the page's tree. A central CSS block scoped via body:has(.shared-print-surface) handles both cleanly. Tailwind inline classes are used for the per-element bits (sticky header, CTA banner, bubble break-inside) because they keep the diff readable in the JSX.
2026-05-29 implement
Added marker class + Tailwind print utilities to SharedChat.tsx and SharedNote.tsx; appended a @media print block to src/index.css.
2026-05-29 test
Verified via Chrome DevTools (Emulate CSS media print) at http://localhost:8081/share/<token>.
Gradient gone, fixed elements gone, header CTA hidden, message bubbles do not split mid-bubble.
