Bug summary

AttachmentPicker empty-state copy (“No notes yet. Create one in Notes.”, “No checklists yet. Create one in Planner.”, “No timeline events yet.”, “No images yet. Generate some in Images.”) is text-only. To act on it the user must close the picker, leave chat, navigate to the right section, create the item, then return to chat and re-open the picker — a 6-step interruption for what should be a 1-tap CTA.
