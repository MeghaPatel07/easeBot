WE-20260528-1066 · motion-safe variants on infinite animations (WCAG 2.3.3) P3

Repo: Wedding-Ease-Viva-Chat · Agent: fix-frontend · Branch: fix-WE-20260528-1066 → Bug-Resolve-claude · Worktree: worktrees/fix-WE-20260528-1066

Bug summary

Tailwind's animate-pulse and animate-[shimmer_1.8s_ease-in-out_infinite] leak through the global prefers-reduced-motion: reduce reset in src/index.css. The reset clamps animation-duration: 0.01ms and animation-iteration-count: 1, but one full 1.8s cycle of shimmer / one pulse still plays because the reduced iteration count is still ≥ 1. For vestibular-disorder users, one cycle can trigger symptoms. Fix: wrap the animation utilities in Tailwind's motion-safe: variant so they don't apply at all when reduce-motion is set.
