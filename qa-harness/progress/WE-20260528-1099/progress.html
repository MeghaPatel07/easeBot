WE-20260528-1099 · WeddingEaseFloater overlaps content on mobile (WCAG 2.4.11) P2

Repo: Wedding-Ease-Viva-Chat · Agent: fix-frontend · Branch: fix-WE-20260528-1099 -> Bug-Resolve-claude · Worktree: /Users/krish/Desktop/easebot/worktrees/fix-WE-20260528-1099

Bug summary

The WeddingEaseFloater component renders a fixed-position decorative anchor at bottom-6 right-6 with z-[60]. On mobile viewports (<640px), this fixed element can overlap and obscure focusable controls in the bottom-right corner (FAQ chevrons on /help, share buttons on chat messages, mic button on chat input), violating WCAG 2.4.11 Focus Not Obscured (AA). Additionally, the existing aria-label="Open WeddingEase in a new tab" was misleading because the href, target="_blank", and onClick were commented out leaving an inert href="#" anchor.
