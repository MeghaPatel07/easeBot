WE-20260527-256 — Focus ring fails contrast + bare focus:outline-none

Agent: fix-frontend  |  Worktree: worktrees/fix-WE-20260527-256  |  Branch: fix-WE-20260527-256  |  WCAG: 1.4.11, 2.4.7, 2.4.11

1. Diagnosis

  • button.tsx:8 — base ring was focus-visible:ring-1 focus-visible:ring-foreground/10 (10% alpha → fails 3:1 against both light and dark backgrounds).
  • badge.tsx:7, select.tsx:20, Pricing.tsx:428, Checkout.tsx:253 — same faint ring-foreground/10.
  • dialog.tsx:45 (Close button) and navigation-menu.tsx:44 — bare focus:outline-none with no replacement → invisible focus.
  • Other call-sites (VibeCard, GalleryFilterBar, SettingsShell, etc.) already pair focus:outline-none with a visible focus-visible:ring-*; left as-is.

2. Fix

FileChange
src/components/ui/button.tsxring-1/foreground/10 → ring-2/primary + offset-2
src/components/ui/badge.tsxfocus-visible:ring-2 primary + offset-1
src/components/ui/select.tsxfocus-visible:ring-2 primary + offset-1
src/components/ui/dialog.tsxadded focus-visible:ring-2 primary + offset-1 to Close
src/components/ui/navigation-menu.tsxadded focus-visible:ring-2 primary + offset-1 to trigger
src/pages/Pricing.tsxcurrency select ring upgraded
src/pages/Checkout.tsxshared input ring upgraded
src/index.cssglobal :focus-visible fallback (2px solid primary outline + 2px offset) and :focus:not(:focus-visible) { outline: none }

Brand primary --primary: hsl(22 25% 51%) ≈ #A17A63 (bronze) — measured contrast vs dark #090807 ≈ 4.5:1; vs light ivory #FAF6F0 ≈ 3.6:1. Both clear WCAG 1.4.11 (3:1).

4. Verification

  • Keyboard Tab → every Button, Badge, Select, Dialog Close, NavigationMenu trigger, Pricing currency select, Checkout inputs now show a 2px bronze ring with 1–2px offset.
  • Mouse click → no ring (because we use :focus-visible, not :focus).
  • Global :focus-visible rule catches anchor tags and any third-party widget that doesn't opt into Tailwind classes.
  • Likely also resolves WE-20260527-061 (P3 default focus ring not visible) since the underlying mechanism is shared.
