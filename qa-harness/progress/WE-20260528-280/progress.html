WE-20260528-280 · Page <title> identical across all 9 routes (WCAG 2.4.2) P2

Repo: Wedding-Ease-Viva-Chat · Agent: fix-frontend · Branch: fix-WE-20260528-280 → Bug-Resolve-claude · Worktree: worktrees/fix-WE-20260528-280

Bug summary

Every route returns document.title === "TheWeddingBot - Your Personal Wedding Planning Assistant" because the title is only set statically in index.html. No React Helmet, no router-driven title hook. Fails WCAG 2.4.2 Page Titled (Level A). SR users with multiple tabs cannot tell pages apart.

Fix shape

Added a small usePageTitle(title) hook (no new deps) that sets document.title in a useEffect and restores on unmount. Pattern mirrors the existing useCanonical hook. Wired only to pages with no open PR collisions: PrivacyPolicy.tsx, TermsOfService.tsx, PaymentFailure.tsx. All other pages (Index, Login, Pricing, PaymentSuccess, Help, Checkout, NotFound, SharedChat, SharedNote) are deferred to follow-up PRs after their respective collision PRs merge.
