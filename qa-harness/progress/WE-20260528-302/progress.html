Bug summary

Vite build emits a single mega-vendor chunk because manualChunks was originally absent. An interim fix (PR #24, BUG-VIVA-20260525-303) added grouping but introduced a CIRCULAR CHUNK warning (vendor-react -> vendor -> vendor-react) because the bare react package and @tanstack/react-query still fell into the catch-all vendor chunk. This PR fixes the missing patterns and refines the grouping per ticket spec.
