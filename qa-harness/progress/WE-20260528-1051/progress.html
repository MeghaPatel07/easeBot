WE-20260528-1051 - Auth forms missing autocomplete attributes (WCAG 2.2 SC 3.3.8) P1

Repo: Wedding-Ease-Viva-Chat · Agent: fix-frontend · Branch: fix-WE-20260528-1051 -> Bug-Resolve-claude · Worktree: /Users/krish/Desktop/easebot/worktrees/fix-WE-20260528-1051

Bug summary

Email / password / phone / OTP inputs across SignInModal, SignUpModal, and PhoneInput carry no autoComplete attribute. WCAG 2.2 Level AA SC 3.3.8 Accessible Authentication (Minimum) and SC 1.3.5 Identify Input Purpose require these so password managers (1Password, Bitwarden, iCloud Keychain) can autofill credentials. Without them, users must hand-transcribe email / password / OTP every visit - excluding users with cognitive impairments and defeating the purpose of password managers.
