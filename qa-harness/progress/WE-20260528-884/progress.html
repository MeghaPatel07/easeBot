Bug summary

The NotificationPanel empty-state copy says "You'll see reminders for upcoming deadlines here", but notifications come from checklist due-dates, timeline events, shared notes, or payment events. A free-tier user with no checklists/no collaborators has no path to ever see a notification, so the copy is a dead-end. Fix: branch the empty-state copy on user state and surface a CTA toward the action that would enable notifications.
