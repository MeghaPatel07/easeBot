Bug summary

TimelineView.tsx line 718 guarded the friendly empty-state on entries.length === 0 && !weddingDate. The very common path (user sets wedding date in onboarding, opens Timeline before adding any checklist due dates or events) fell through the guard and landed on the main render, producing a near-empty timeline with month headers and a vertical axis but no event chips. Users assume the page is broken.
