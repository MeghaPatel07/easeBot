WE-20260528-1055 · useTypewriter ignores prefers-reduced-motion P1

Repo: Wedding-Ease-Viva-Chat · Agent: fix-frontend · Branch: fix-WE-20260528-1055 → Bug-Resolve-claude · Worktree: worktrees/fix-WE-20260528-1055

Bug summary

src/index.css:872 globally applies prefers-reduced-motion: reduce to kill CSS animation/transition. However useTypewriter is a JS hook driven by requestAnimationFrame at 12 ms/char — entirely unaffected by CSS media queries. Users with motion-reduction enabled still see every assistant message animate char-by-char for 5–30 s. This violates WCAG 2.2.2 (Level A — Pause/Stop/Hide) and 2.3.3 (AAA — Animation from Interactions).
