Behavior preserved

  • Early track() / identify() / register() calls are buffered (bounded queue, 200 entries each) and flushed when posthog.init() resolves.
  • Consent decision (localStorage('ph_consent')) is re-applied inside init, so user opt-out before SDK load is respected.
  • useFeatureFlag's onFeatureFlags subscriptions are buffered and resubscribed once PostHog loads; flag reads default to false until then.
  • startReplay is queued pre-init and decided + started once PostHog loads.
