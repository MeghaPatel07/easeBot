  </div>

Helper added at top of file:

  const RTL_LANGUAGE_CODES = new Set(['ar', 'he', 'fa', 'ur', 'ps', 'yi', 'dv']);

  function isRtlLanguage(code?: string): boolean {
    if (!code) return false;
    const primary = code.toLowerCase().split('-')[0];
    return RTL_LANGUAGE_CODES.has(primary);
  }

Behavior change:

  (assuming the user's screen reader has a Hindi voice installed; if not,

  reader treats them as Arabic for both phoneme + reading-order purposes.
- Existing English chats are unaffected aside from the (already implicit)
  inherited "en" being made explicit.
